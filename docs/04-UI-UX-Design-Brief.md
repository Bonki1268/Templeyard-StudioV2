# 04 UI / UX Design Brief：長怎樣

廟埕影室（Templeyard Studio）· 2026-11-02

視覺稿：「廟埕影室 UI 設計」畫布（10 個畫面）。本文件是實作時的規範；畫布與本文件不一致時，以本文件為準並回頭更新畫布。

## 風格

- **關鍵字**：溫暖、樸實、可信；像在廟埕前慢慢說故事，而不是科技感的 AI 工具。
- **主色只用一個**：朱紅，用在主要按鈕、品牌標誌與少數重點。
- **AI 有自己的顏色**：金色只用在「AI 幫我寫」與「AI 建議」，讓使用者一眼分辨哪些內容是 AI 提議、尚未採用。
- **不使用**：漸層背景、玻璃擬態、左邊框強調卡片、表情符號當圖示、逐格跑動的進度動畫。

## 字體

| 用途 | 字體 | 大小 / 字重 |
| --- | --- | --- |
| 頁面標題 | Noto Serif TC | 28–40px / 700 |
| 區塊標題 | Noto Sans TC | 16–20px / 700 |
| 內文 | Noto Sans TC | 15–16px / 400，行高 1.6–1.7 |
| 說明、標籤 | Noto Sans TC | 12–14px / 400–500 |
| 連續性鎖、指令 | 等寬字體 | 12–14px |
| 時間、秒數 | Noto Sans TC，等寬數字 | `font-variant-numeric: tabular-nums` |

## 間距與形狀

- 間距以 4 的倍數：4、8、12、16、20、24、32、40。
- 圓角：按鈕與輸入框 8px；卡片 12px；標籤與 AI 按鈕全圓角。
- 陰影：不使用；以邊框與底色區分層次。

## 元件

| 元件 | 規格 |
| --- | --- |
| 主要按鈕 | 朱紅底白字，高 48px；每個畫面最多一個，固定在底部操作列 |
| 次要按鈕 | 白底、`--color-border-input` 邊框，高 44px |
| AI 幫我寫 | 白底、金色邊框、金色文字，左側星芒圖示，全圓角 |
| AI 建議區塊 | `--color-ai-surface` 底、標題「AI 建議」，按鈕「採用」（深色）、「再寫一版」、必要時「略過」 |
| 選項按鈕（單選） | 未選：白底細框；選取：2px 深色框＋淺底＋粗體；`aria-pressed` 標示狀態 |
| 或自己寫 | 每題選項下方一行：標籤＋輸入框＋AI 幫我寫；填寫時取消選項 |
| 模型標籤 | 頂端列，鎖頭圖示＋「圖片 / 影片 模型名稱」 |
| 費用表 | 頂端列「費用 已用 / 上限」；操作列顯示這次的預估 |
| 底部操作列 | 黏在畫面底部；左側說明未通過的原因或費用，右側主要按鈕 |
| 對話泡泡 | Agent：淺底、靠左；使用者：深底白字、靠右 |
| 分鏡卡片 | 序號與時間、對應照片縮圖、標籤列（景別運鏡、視角、狀態）、畫面、台詞、字幕與估時、右側操作（細修、AI 幫我寫、更多） |
| 時間軸條 | 每格寬度依秒數比例；有問題的格以錯誤色框標出；邊界可拖曳，也可用鍵盤調整 |
| 視角圖卡 | 16:9 預覽、視角名稱、來源標籤（依照片／AI 推測）、重生與修改 |
| 照片卡 | 4:3 縮圖、「已去識別」標籤、可開啟遮蔽編輯 |
| 狀態標籤 | 系列預設、自己寫、需重新確認、缺少視角、AI 推測・待確認、依照片、已選定 |
| 生成中 | 置中的圓形指示＋「生成中」＋內容類型；`role="status"`；減少動態模式下靜止 |
| 折疊區塊 | 細修頁的設定以 `<details>` 分段：內容、鏡頭、參考素材、畫格、生成設定、進階：生成指令、版本 |

圖示使用同一套線條圖示（建議 Lucide），線寬 1.8，不使用表情符號。

## 畫面

| 畫面 | 版面 | 重點 |
| --- | --- | --- |
| 系列首頁 | 左：系列卡片列表；右：建立新系列表單 | 新增影片是系列卡片上的主要動作 |
| 建立影片 | 單欄、步驟列（選寺廟 → 選模型 → 上傳照片 → 定裝版） | 模型鎖定的提醒放在模型區塊標題旁 |
| 寺廟定裝版 | 視角圖卡網格；下方外觀規範與光線 | AI 推測的視角未確認前，主要按鈕不可按並說明原因 |
| 創作工作區 | 左欄對話（約 340px）＋右欄面板 | 寬度不足 1024px 時，對話收合到底部抽屜 |
| 創作首頁 | 右欄置中：大標題、輸入框、快捷標籤 | 寺廟照片已帶入的提示 |
| 設定問卷 | 每題一張卡片；短題以兩欄網格排列 | 標籤顯示答案來源 |
| 分鏡方案 | 上：風格、角色、場景三張卡；中：時間軸；下：分鏡卡片 | 未通過的檢查列在底部操作列 |
| 分鏡細修 | 左對話、中預覽與單格時間軸、右設定面板 | 上方縮圖列切換格；模型顯示為鎖定 |
| 生成中 | 右欄置中狀態 | 告訴使用者可以離開 |
| 精緻圖 | 卡片網格 | 需重新確認的格以警告色框標出 |
| 成品 | 播放器、各格縮圖條（依秒數比例）、模型與規格資訊 | 主要按鈕「確認並下載」 |

## 文案規則

- 繁體中文、台灣用語；口語、短句。
- 按鈕用動詞開頭：「產生寺廟定裝版」「建立分鏡方案」「確認並下載」。
- 不能按的按鈕旁邊一定說明原因（例如「還有 2 項待處理：…」）。
- 花錢的按鈕旁邊一定有費用預估。
- 尚未決定的數字以方括號占位，例如「[金額]」，不寫假數字。

## 互動與無障礙

- 所有可點的東西都是 `<button>` 或 `<a>`；圖示按鈕有 `aria-label`。
- 點擊目標至少 44×44px（標籤內的小按鈕至少 36px 高）。
- 焦點框：3px 深色外框，所有互動元件都看得到。
- 文字對比至少 4.5:1；色彩不是唯一的狀態提示。
- 拖曳（卡片排序、時間軸邊界）都有鍵盤替代方式（上下移動、加減秒數按鈕）。
- 動畫只用在狀態切換與「生成中」指示；尊重 `prefers-reduced-motion`。
- 「生成中」與完成通知以 `role="status"`／`aria-live="polite"` 宣告，不搶焦點。
- 錯誤訊息放在欄位下方，說明原因與修正方式。

## 響應式

- 斷點：1024px、768px。
- ≥ 1024px：兩欄（對話＋面板）；細修頁三欄。
- 768–1023px：對話收合為可展開的抽屜；細修頁的設定面板移到預覽下方。
- < 768px：單欄；個人使用以桌機為主，手機只需能檢視與下載成品。
