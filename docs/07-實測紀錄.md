# 07 實測紀錄：Comfy Cloud

廟埕影室（Templeyard Studio）· 第 0 階段 · 測試於 2026-11-01～02 · 測試程式：`comfyui-test/`

## 結論

- **串接方式已驗證**：透過 Comfy Cloud 的 MCP 端點（`https://cloud.comfy.org/mcp`，JSON-RPC over HTTP），以 `X-API-Key` 驗證，可以送出生成、輪詢狀態、取得輸出並下載回本機。
- **花費確認是雲端原生的**：付費任務第一次呼叫時，Comfy Cloud 會回一段要求確認的文字、不啟動任務；使用者同意後帶 `confirm: true` 再呼叫一次才會執行。這可以直接對應本系統的「付費生成前先同意」。
- **中斷恢復可行**：拿到 `prompt_id` 後寫入紀錄；伺服器重啟時以 `prompt_id` 繼續追蹤，不重新送出。
- **Gemini Omni 1.1 Flash 文字生成影片已驗證**（第二輪）：沒有 `partner_generate` 代號，要用官方範本 `run_template`：`api_google_gemini_omni_flash_1_1_t2v`。
- **尚未驗證**：參考圖、首尾畫格（Gemini 的圖片輸入範本）、Nano Banana Pro、1080p 影片、中文對口型、自訂工作流程（Wan 多關鍵畫格）。這些是本系統最關鍵的部分，見文末「下一輪測試」。

## Gemini Omni 1.1 Flash 的呼叫方式

- 範本：`api_google_gemini_omni_flash_1_1_t2v`，以 `input_overrides` 改第 26 號節點：
  - `model.prompt`：影片長度寫在指令裡（例如「A 4-second, 16:9 clip. …」），範本沒有長度欄位；可用 3～10 秒。
  - `model.aspect_ratio`：`16:9` 或 `9:16`。
  - `model.resolution`：本輪用 `720p`。
  - `model.task_type`：本輪用 `text_to_video`；這個欄位表示範本還有其他模式，圖片輸入（首格、末格、參考圖）應該就在這裡，待確認。
  - `model.seed`：亂數。
- 輸出長度精準（指令寫 4 秒，輸出 4.00 秒），對分鏡秒數有利。
- 參考單價：約 31 credits／秒（測試程式的註記，尚未以實際扣點核對）。
- 指令中寫「16:9、1920×1080、24 fps」不會讓輸出變成 1080p；解析度由 `model.resolution` 決定。


## 已確認的 MCP 呼叫流程

1. `initialize` → `notifications/initialized`，回應標頭 `Mcp-Session-Id` 之後每次都要帶；收到 404 代表 session 過期，重新初始化一次。
2. `tools/call`：
   - `partner_generate`：合作節點模型，參數 `type`（image／video／audio）、`model`、`prompt`、`params`、`aspect_ratio`。
   - `run_template`：官方範本，以 `slot_overrides` 或 `input_overrides` 改節點參數。
3. 回應中取 `prompt_id`；若回的是要求確認的文字，顯示給使用者，同意後加 `confirm: true` 重送。
4. 以 `get_job_status`（`prompt_id`）輪詢，`job_status` 為 completed 即完成；error／failed／cancelled 為失敗。
5. 以 `get_output`（`prompt_id`）取得輸出連結（短連結優先），下載存檔。

## 下一輪測試（仍屬第 0 階段）

每項用一格分鏡、一次生成即可，並記下實際扣點。

1. **列出可用工具與參數**：呼叫 MCP 的 `tools/list`（不花錢），確認 `partner_generate` 與 `run_template` 怎麼收圖片，以及如何上傳本機圖片。
2. **Gemini 圖片輸入**：找出 `task_type` 的其他值與對應範本（圖片生成影片、首尾畫格、參考圖）；以「首格＋末格＋參考圖」生成一次，確認能否同時使用、參考圖最多幾張。
3. **Gemini 1080p**：把 `model.resolution` 改成 `1080p` 試一次；不支援就記下來，評估合成時升頻。
4. **Nano Banana Pro**：以 `vertexai/nano-banana-pro` 用照片＋角色參考圖生成一張 16:9 精緻圖，看廟和角色是否一致。
5. **中文對口型**：給一句中文台詞，看口型與發音；記下實際語速，取代對白估時的暫定值（每秒約 4 字）。
6. **去背景音樂**：在影片指令中要求「不要背景音樂」，確認自帶音訊是否只剩人聲與環境音。
7. **Wan 多關鍵畫格**：在 MCP 上找 Wan 的範本（`run_template`），確認能否在中間時間點指定畫面。
8. **Seedance 2.0、Wan 2.2 比較**（選做）：同一格分鏡各生成一次，比較費用、角色一致性與對口型。
9. **Z-Image Turbo 再測**（選做）：確認上次 449 秒是否為冷啟動。
