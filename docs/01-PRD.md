# 01 PRD：要做什麼

廟埕影室（Templeyard Studio）· 依系統規格書 v8 整理 · 2026-11-02

## 一句話

讓不會編劇、不會剪片的人，選一間新北市寺廟、上傳幾張照片、說一句想講的故事，就能和 AI 一起做出 30 秒以內、角色與場景一致的寺廟觀光短影音。

## 背景與問題

- 現有 AI 工具各自只解決一段（寫文案、出圖、做影片），每支影片都要從頭拼接，系列風格也很難一致。
- 寺廟題材有兩個額外風險：AI 容易捏造寺廟歷史，以及照片裡常有信眾與路人的臉。
- 本系統把「素材 → 故事 → 分鏡 → 圖 → 影片」串成一條可確認、可重複的流程，每一個花錢的步驟都先讓使用者確認。

## 使用者

- **目前**：開發者本人，在自己的電腦上使用，不對外開放，不需要登入。
- **之後可能**：觀光業者、地方文化推廣者、廟方。手上有照片與在地故事，但不具編劇、分鏡與影片製作能力。

## 核心概念

| 名詞 | 意思 |
| --- | --- |
| 系列專案 | 一組影片共用的風格、方向、角色、預設模型與問卷預設值（影片秒數每支影片在問卷選） |
| 寺廟定裝版 | 一間廟的場景規範：數張固定視角的空景圖、外觀連續性鎖、預設光線 |
| 角色定裝版 | 角色的三視圖、定裝圖與連續性鎖 |
| 連續性鎖 | 一條固定短語（例如服裝、屋脊樣式），逐字帶進每一次生成指令，讓外觀不跑掉 |
| 分鏡方案 | 每一格的秒數、景別、運鏡、畫面、台詞、字幕、場景視角；生成前唯一的大檢查點 |
| 分鏡細修 | 對單一格做更細的控制（鏡頭、參考素材、中間關鍵畫格、自訂指令、版本） |
| 中間關鍵畫格 | 在一格的首格與末格之間，指定時間點的畫面 |
| AI 輔助撰寫 | 每個需要輸入文字的地方都有「AI 幫我寫」，先給建議、使用者採用才填入 |

## 功能清單（第一版要有的 features）

| # | Feature | 使用者可以做什麼 | 怎樣算做好 |
| --- | --- | --- | --- |
| F1 | 系列專案 | 建立、檢視、修改系列；系列頁分「系列設定」「角色庫」「過去的影片」三個分頁：設定風格、方向、預設圖片與影片模型、問卷預設值、費用；角色庫（新增、修改、版本、產生定裝圖、影片專屬角色設為系列角色）；過去的影片（篩選、排序、繼續製作、複製、下載） | 首頁列出系列；修改只影響之後新增的影片（影片建立時保存系列設定）；問卷預設值可逐題修改 |
| F2 | 寺廟搜尋 | 以廟名、行政區、主祀神明搜尋新北市寺廟資料庫 | 940 間有效寺廟可搜；排除已廢止與未登記；「臺／台」與「財團法人新北市」前綴可模糊比對 |
| F3 | 建立影片與選模型 | 選寺廟後選圖片模型與影片模型 | 產生寺廟定裝版後模型鎖定，之後所有畫面都不能更換 |
| F4 | 照片上傳與去識別 | 上傳 1～5 張寺廟照片，查看去識別結果，手動增減遮蔽 | 只有去識別後的圖會送到雲端；原圖只存本機；神像臉部可手動取消遮蔽 |
| F5 | 寺廟定裝版 | 依視角清單產生空景視角圖，單張重生或修改，確認後沿用 | 每張視角圖標示「依照片／AI 推測」；AI 推測的必須確認；同系列同一間廟可直接沿用 |
| F6 | 創作對話 | 一句話說出想做什麼，快捷標籤帶入開頭 | Agent 回覆說明下一步並開啟問卷 |
| F7 | 設定問卷 | 每題點選項或自己寫；留白由系統決定 | 第一支影片的答案存成系列預設；「想講的故事」等每支影片不同的題目不沿用 |
| F8 | 分鏡方案 | 檢視、編輯、拖曳排序、新增刪除卡片；拖曳時間軸調秒數；用對話修改 | 每次修改產生新版本可回溯；秒數檢查不過時「生成」不可按 |
| F9 | 秒數與對白檢查 | 即時看到總長、最短生成長度、對白估時 | 對白放不下時標紅，建議縮短或拆格，不要求加快語速 |
| F10 | 角色定裝版 | 沿用系列角色或建立新角色，產生三視圖與定裝圖 | 角色確認後才能生成精緻圖 |
| F11 | 補充視角 | 分鏡需要但定裝版沒有的視角，在方案中補產生 | 卡片標示「缺少視角」，補完確認才可生成 |
| F12 | 分鏡細修 | 在方案、精緻圖或成品中點任一格進入，調整內容、鏡頭、參考素材、畫格、生成設定、自訂指令、版本 | 修改後該格標示「需重新確認」；時間軸與秒數檢查即時更新 |
| F13 | 中間關鍵畫格 | 在細修頁加入時間點（最多 4 張，至少相隔 1 秒） | Gemini／Seedance 為軟性控制，Wan 為精準控制；生成後顯示偏差比對 |
| F14 | 精緻圖生成 | 按「生成」後產生每格首格（與末格、關鍵畫格） | 生成期間只顯示「生成中」；完成後一次顯示；可單格重生 |
| F15 | 影片生成與合成 | 確認精緻圖後生成每格影片並合成成品 | 成品 30 秒以內、16:9、1920×1080、24 fps；繁中字幕逐字取自卡片；統一響度 |
| F16 | 成品修改與下載 | 用對話提出修改、點任一格細修、下載成品 | 修改前先顯示費用；成品資訊列出使用的模型 |
| F17 | 複製影片 | 複製寺廟、問卷與分鏡方案到新影片，改選其他模型 | 不複製已生成的圖片與影片 |
| F18 | AI 輔助撰寫 | 所有確認點的文字欄位都能按「AI 幫我寫」 | 先顯示「AI 建議」，按「採用」才填入；不會自動送出或觸發生成 |
| F19 | 費用控制 | 每次付費生成前看到預估；頂端看到累計與上限 | 預估 → 預留 → 結算；超過門檻或上限需再次同意 |
| F20 | 生成指令管理 | 在管理頁編輯各節點的生成指令、預覽、看歷史版本 | 儲存驗證、版本保留、衝突提示；每筆生成記錄指令版本 |
| F21 | 任務中斷恢復 | 系統重啟後自動取回已送出的任務 | 不重複送出、不重複付費 |
| F22 | 通知 | 生成完成或需要確認時收到通知 | 使用者可離開頁面 |

## 這一版不做的東西

- 登入、帳號與權限；多人同時編輯同一系列
- 自動發布到社群平台
- 新北市以外的寺廟；另接寺廟歷史資料來源（歷史由使用者自己貼上）
- 多語字幕、原生 App
- 在本機 GPU 執行生成（圖片與影片一律透過 Comfy Cloud MCP）
- 同一支影片內切換模型
- 文字特效（浮動關鍵字）
- 生成過程逐格顯示進度（只顯示「生成中」）
- 計費、付款或訂閱功能（費用由使用者自行負擔，系統只做預估與上限）
- 影片的剪輯時間軸編輯器（成品由系統合成，修改靠細修與重生）
- 中國的模型作為預設；Seedance、Wan 只在使用者自行選擇時使用

## 使用者故事

- 身為使用者，我想用一句話說出影片要講什麼，讓系統幫我補齊細節，不用自己寫腳本。
- 身為使用者，我想在花錢之前看到每一格的秒數、畫面和台詞，確定沒問題再生成。
- 身為使用者，我想讓同一個系列裡的角色和廟長得一樣，不會每支影片都變樣。
- 身為使用者，我想只改某一格，不想因為一格不滿意就整支重來。
- 身為使用者，我想確定照片裡的路人臉孔不會被送到外部服務。
- 身為使用者，我想知道每支影片花了多少錢、用了哪些模型。

## 內容與宗教規則

- AI 只能引用寺廟資料庫與使用者提供的內容，並標示來源；沒有來源的寺廟事實不得出現。
- 不產生對神明不敬的動作與場景。
- 不出現可辨識的真實民眾。
- 神像外觀與匾額、對聯文字以照片為準；AI 推測的部分必須使用者確認。
