# 表演弧、動作預算與節奏

## 時長門檻

- `VID-04` — 顯式標時的各段必須合計等於已接受的鏡頭時長：超出與留下未分配餘量同樣違約。
- `VID-05` — 未標時的動作負載屬於 `reviewed_invariant`：根據本鏡頭證據審查
  表演和故事變化是否仍可讀，不套通用“每秒幾個動詞”公式。

## 目錄

1. 動作預算不是計數器
2. 構造可演的動作鏈
3. 構造可見的表演變化

5. 超載修訂與審查

## 1. 動作預算不是計數器

動作預算要判斷：在已接受的鏡頭時長內，演員能否保持故事重點，清楚完成必要動作、反應、對白併到達終點？它不是“每鏡最多三個動詞”或“每秒固定字數”。動作距離、接觸複雜度、語言節奏、停頓、表演強度與相機是否需要等待，都比動詞數量重要。

**`reviewed_invariant`**：整體可行性由審查者結合分鏡、運動說明、對白和時長判斷。顯式分段超時或未覆蓋完整鏡長則按 `VID-04` 判為 `structural_invariant`。

## 2. 構造可演的動作鏈

### 先找不可刪的主動作

從鏡頭目的反推：

- 哪個動作造成資訊/權力/情緒變化？
- 哪個反應讓觀眾讀懂變化？
- 哪個動作必須完成才能到達已接受終點？
- 哪些只是“讓畫面忙起來”？

先保留主動作，最後加入裝飾動作。短鏡頭常見的有效結構是“一次決斷動作 + 一次對方或自身反應”，但這只是 **`craft_default`**。

### 給動作以條件與結果

每個動作階段至少明確行動者、方向或物件，以及到達結果。接觸動作注意順序：先靠近、再觸碰、再施力、物體才變化；持物轉手必須寫清哪隻手、何時釋放/接住。角色不能在同一時刻用同一隻手完成不相容任務。

空間位移要符合鏡頭起點已有的距離和障礙。若同鏡要求穿過房間、開鎖、取物、返回並說完長對白，
應先核對鏡頭邊界和時長；放不下時向分鏡提出修訂請求。

### 同時發生的合理用法

“同時”適合可自然疊加的通道：角色說話時緩慢抬眼，環境雨聲持續，攝影機平穩跟隨。不要用它壓縮互為條件的動作，或讓雙手/身體執行物理衝突。

## 3. 構造可見的表演變化

### 角色不是情緒滑塊

不要機械排列“平靜 30% → 緊張 70% → 震驚 100%”。從角色目標和觸發選擇外顯通道：

- 目光：尋找、迴避、鎖定、短暫失焦；
- 呼吸/聲音：吸氣被截斷、語速變化、音量反常降低；
- 身體：重心撤後、肩線防禦、手指停止或反覆動作；
- 語言：停頓、吞字、改稱呼、打斷或刻意完整地說完；
- 決斷動作：收回手、讓路、把物件推回、關門。

選擇能被當前景別讀到的訊號。遠景不應依賴細微眼瞼變化；近景不必用誇張全身後退替代內心處理。

### 可選：表演標尺只用來校準形容詞

只有創作者已經宣告並接受一套表演標尺時才使用它。沒有創作者標尺時直接寫可見表演，不自行增加刻度、增量公式或每鏡升壓規則。

標尺用於明確**一個情緒形容詞在當前角色和場合下對應什麼可見表演**。例如這裡的“不安”
是欲言又止，還是手抖到握不住杯子；取值從角色、觸發和後果判斷，不要求後一鏡比前一鏡更用力。這也是
[production-prompt-grammar.md](production-prompt-grammar.md) 裡“哪些情緒形容詞可刪”的
另一面：能被標尺定住落點的形容詞才值得留下，定不住的應當換成可見動作。

用法：

- **取值來自形容詞本身**，由人物、觸發和後果決定落點；不從鏡號、段序或“第幾次升級”
  推導。同一個詞在本集第 3 鏡和第 30 鏡可以是同一個落點。
- **保持與變化同樣合法，而且保持更常見**。相鄰段之間不變是最常出現的正確選擇：一個
  角色可以在整場戲裡維持同一強度，變化發生在別人身上或發生在資訊上。為了“有層次”
  每段都動一格，是把標尺當節拍器用。
- **按最小可見增量變化**。相鄰段之間的改變小到剛好能被當前景別看見即可；跨段一次跳
  多級必須有段內可指認的觸發（一句台詞、一次接觸、一個揭示），否則觀眾看到的是換了
  個人，而不是同一個人變了。
- **只標註本段真正參與變化的角色**。旁觀者、畫外角色和狀態未變的人不進標註；為“欄位
  齊全”給全場人各標一個值，會讓審查者分不清哪一處變化是有意的。
- **數字不替代表演**。標尺值旁邊必須仍有可見通道（目光、呼吸、身體、語言、決斷動作）；
  只有數字的表演等於沒寫表演。

劇本的 `（情緒）` 括注同時約束表演狀態和說話方式。標尺值、可見
表演與台詞的說話方式都應當從這一個括注派生；三者互相矛盾時以劇本括注為準，需要改動
就發修訂請求，不在提示詞裡自行折中。

### 單人或多人表演弧

每個真正承擔本鏡可見變化的角色才寫一條；狀態未變的旁觀者不因欄位完整度進入主表演通道。
以下是可選詞彙，不是六項必填拍表：

1. **agenda**：他此刻想維持或取得什麼；
2. **receive**：準確觸發怎樣被角色接收；
3. **mask**：角色確實在掩飾、繼續或壓住什麼時才寫；
4. **visible_leak**：掩飾漏出的目光、尾音、手部、距離或物件動作，且當前景別讀得到；
5. **choice**：說、做或刻意不做一個有方向的選擇；
6. **landing**：選擇落在分鏡明確的終點狀態。

需要時在對應 `MOTION-...` 下按人物分條寫；人物使用 `視覺設定.md` 的穩定 ID，觸發與注意交接指向
場景或鏡頭的可見 ID，不靠同名猜身份。
只保留能讓本鏡更可演、更可讀的欄位。例如角色認出桌上印章後仍試圖把原句說完，尾音降低、
右手離桌，最後停止阻攔並讓出通道；若沒有掩飾，就刪除 `mask` / `visible_leak`，不要填 `none`。

若本鏡只需要“聽見門響後停止翻頁”，寫觸發和可見動作即可，不必把其餘欄位補成同義句。

空鏡、道具細節、純空間轉場、無人物鏡頭，或只有物理動作而沒有可見內在處理的鏡頭，省略
表演弧。單人鏡也不因人數自動生成；多人鏡更不是給每個人複製同一“震驚”。不同人物可以早認出但繼續說、
晚半拍才讓路、故意製造噪聲掩飾，或看見別人停頓後才理解變化。所有差異都要來自角色立場、
已接受資訊和空間關係。

### H3 反應鏡：先點名，再給兩處可見洩露（`craft_default`）

目標為 H3、且一鏡的職責就是接收一個訊息（震驚、被打臉、得意、壓怒）時，按這個順序寫：觸發 → 一個情緒詞點名
「他立刻震驚」→ 兩處當前景別讀得到的洩露（目光停住、拇指懸住；笑容停住、手臂收緊）→ 落點並定住。
反應在觸發後一秒半內落下，剩下的時間給落點。

H3 實測四個反應節拍，這種寫法盲評清晰度 3.9/5、自然度 4.0/5，四拍全部排第一或並列第一；只寫情緒詞會演過頭
（強度 4.3、自然度 2.8），把可見反應逐段寫滿又太弱（強度 1.9），「不動聲色的得意」這類反應尤其會被讀錯。
情緒詞在 H3 這套寫法裡是給表演定調的錨，不是可刪的形容詞；鏈條仍要寫，但只寫兩步。

Seedance 2.5 樣片檔的同輪對照以逐段可見反應鏈最好，保留上文完整的觸發、處理、可見反應與落點，
不套用 H3 的兩處洩露與 1.5 秒預設；具體見 `seedance-2.5.md`。其他模型沿用可見表演原則並實測，
這輪證據不支援把 H3 配方外推成通用約束。

只在注意真正交接時，簡寫“誰/什麼擁有注意 → 哪個可見或可聽觸發 → 注意轉給誰/什麼”；沒有交接
就不補這一段。交接兩端可以是角色、道具、證據、聲源或已建立的空間區域；使用它們在
`視覺設定.md` / `分鏡.md` 中的可見 ID，不要為了套人物格式把道具或空間偽裝成角色。
交接不是全員同步轉頭：例如說話者尾音降低 → 最近的聽者先停手 → 群體讓路 → 主角獲得空間。
每一跳說明為何當前景別、遮擋和聲音能讀到；細微眼神在遠景不可讀時，改成視線轉移加手部停頓，
而不是隻增加情緒形容詞。

- **`craft_default`**：若一鏡只有資訊接收，寧可把變化做小而清楚，不必每鏡“情緒大爆發”。
- **`reviewed_invariant`**：表演選擇應與人物目標、鏡頭目的相容，不能透過提示詞改寫人物立場。
- **`taste_option`**：停頓多寡、微表演或型別化表演由導演風格決定。

### 反應的物件

明確角色對什麼反應，而不是孤立寫“她突然震驚”。觸發必須來自已接受的分鏡、劇本、聲音，或已可見的環境事實。反應若揭示新知識，要確認角色在這一刻確實獲得它。

## 4. 時間與對白共同預算

### 相對時間優先

在不需要精確秒段時，用“開頭保留一拍”“話音落下後”“動作完成前”“結尾停留”表達節奏。這樣保留演員和剪輯彈性。

### 顯式時間

需要明確計時時，列出各階段及重疊關係：

```text
0.0–0.8s：保持 start，聽見門閂聲後目光轉向門
0.8–2.6s：左手壓住冊頁，身體慢慢前傾（對白從 1.1s 開始，與動作重疊）
2.6–4.0s：說完後停住，右手仍握筆，落到 accepted end
```

區間不可無意重疊；顯式分段不得超出已接受鏡長，其時間並集須完整覆蓋本鏡。存在餘量時，
將餘量分配給已有階段，原因見 [motion-recipe.md](motion-recipe.md) 3.6。不得為湊時長刪掉逐字對白。

### 對白預算

評估：句長與語言、人物語速、情緒造成的停頓/吞吐、是否需要聽見對方或環境中的觸發聲音、口型要求、動作是否能與說話疊加、結尾是否需要反應落點。固定每秒字數只能作為製作檔案中可覆蓋的估算，不能成為通用規則。

**`craft_default`**：先讀取分鏡「聲音」的預算依據。有同句同表演錄音時用實測發聲區間；沒有時按完整原文、
語言和表演方式給出「文字估計」區間，以較慢一端檢查容量，不假稱朗讀或 TTS 實測。對白可用視窗要扣除
開口前等待、不能同時進行的動作、輪流說話的其他發聲與末尾反應；句內停頓已經計入時不再重複扣除。
並行動作可以共享時間，順序事件必須累加。把依據簡寫在當前鏡頭說明裡，不放進可複製正文當成模型指令。

例如已接受鏡長為 7 秒，開場與收尾各佔 0.5 秒，實際只剩 6 秒發聲；若完整台詞估計需要
8–10 秒（含句內停頓），即使寫成「0–7 秒」也不成立。請求分鏡按至少 11 秒重新安排，或按語義拆鏡，
待上游修訂後同步本鏡時長、正文時序和生成設定。不要用更快語速、截斷標記或靜默刪詞讓算術看起來成立。

### H3 中文的估算參考

**`craft_default`**：一次同鏡頭、20 次生成的中文對照中，自然語速約 4.1 個可發聲字/秒。
短鏡裝入更多台詞時先出現趕詞，較長輸入還出現未報錯的截斷；延長鏡頭改善了該組表現。
樣本不能確定通用截斷閾值，其他聲音、表演和模型需要另行校準。

無錄音時可用約 4.1 字/秒輔助估算實際可發聲區間，並另計開口等待、停頓和順序動作。
這不是按整個鏡長計算的保證容量；有音訊時以實際發聲區間為準，生成後回聽是否完整。

這裡的字數不含標點。`duration_estimate.py` 的 `dialogue_characters` 包含標點，
不能直接按這一語速換算發聲時長。

對白太長時選項：

1. 簡化非必要動作，讓對白成為主事件；
2. 若劇本允許，把動作與對白合理重疊；
3. 請求分鏡負責技能延長或拆鏡；
4. 若要改台詞，請求寫作負責技能修訂。

影片提示詞階段不能自行刪字、改詞或把對白變為 VO。

## 5. 超載修訂與審查

### 超載徵兆

- 一個角色完成多次遠距離往返和複雜物件操作；
- 多個角色都有獨立大動作，但鏡頭目的只需要一次揭示；
- 長對白、強情緒轉折、精細手部動作和複雜運鏡爭奪同一幾秒；
- 結尾沒有時間落住，終點狀態只被一句“最後到達”宣告；
- 為了趕時長，動作順序違反接觸因果或表演沒有接收過程。

### 修訂優先順序

1. 刪除無故事功能的環境/手勢活動；
2. 合併可自然連續的動作，保留因果節點；
3. 選擇一個主要注意中心，其他角色只保留必要反應；
4. 保留對白與已接受終點；
5. 仍超載時，向分鏡提出拆鏡、延長或調整走位的修訂請求，不越權執行。

### Reviewer 證據格式

```text
Evidence：SHOT duration 4s；dialogue ref DLG-... 為完整兩句；motion 要求角色從窗邊走到門、開三道鎖、回身交物，並保留結尾反應。
Impact：關鍵交物和反應難以清楚落地，accepted end 可能只被宣告而未實現。
Required fix：刪掉非必要回身動作，或請求 storyboard 拆為兩個 authored shots；不得刪對白。
Classification：reviewed_invariant
Owner：video-prompts（精簡）/ storyboard（改邊界）
```

不要只寫“動作太多”。也不要因提示詞有四個動詞就自動報錯。
