## 這份檔案解決什麼

目標模型檔案記錄會影響提示詞寫法的能力與限制，供分鏡、提示詞和生產階段共同讀取。通用檔案不猜供應商能力；已核對官方契約的
模型可以由本技能的版本化方言檔案提供推薦值。每一條取值都由創作者按自己接入的執行端宣告一次，
本集共用。生產端具體接哪個供應商、用什麼欄位，屬於 `$short-drama-produce` 的 adapter 檔案，不進入創作文件。

還沒選定 `target_video_model` 時，一組小樣本對照（同一起始幀與鏡頭說明，每類每模型 2 次，盲評排序）可作先試哪個的參考：
沒有一個模型在所有鏡頭型別上領先。H3 在建立鏡推近、多人同框只一人說話時最好；Seedance 2.5 在反應鏡、
走位跟搖、手部插入與夜景情緒近景時最好；Wan 3.0 多數型別居中或靠後；單人對白近景三者持平。
本集最多的是哪類鏡頭，就先拿那一類試。

**`craft_default`**： 能力軸是**宣告**出來的，不是推斷出來的。沒有宣告就按“未宣告時怎麼寫”寫；
不要因為某個執行端“據說支援”某種寫法就改寫已接受的鏡頭邊界、時長或起止狀態。

檔案寫在 `short-drama.json#/creator_authority/production_profile/choices`。最小結構如下；未知欄位留空，
不能從模型簡稱補全：

```json
{
  "target_video_model": "versioned-model-profile",
  "video_prompt_dialect": "dialect-id",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 4, "max": 15},
  "supported_generation_modes": ["text", "reference"],
  "audio_generation": "same_pass"
}
```

## 九條會改變正文的能力軸

| 能力軸 | 宣告什麼 | 宣告後正文允許怎麼變 |
|---|---|---|
| 模型版本 | 專案使用的版本化模型檔案鍵；賬號側 Endpoint / model ID 留在生產配置 | 只路由到該版本的方言；不因名稱相近套用另一版本 |
| 提示詞方言 | 通用自然語言 / 目標原生結構及版本 | 命中已有方言時按其欄位、素材標記和聲音語法寫；語言標籤不能代替方言 |
| 單次原生時長 | 一次生成能覆蓋的最短與最長秒數 | 分鏡規劃時就讓每次生成落在區間內：預設一鏡一生成，短動作在合法鏡長內到達終點後 hold；創作者在[交付形態](delivery-profile.md)裡宣告多鏡容器、且命中的方言支援時，短於下限的鏡頭可與同場相鄰鏡頭裝進一次生成，按方言寫（例如 [H3](minimax-h3.md#多鏡容器每切一張關鍵幀) 要求每切都有已接受關鍵幀）。長動作按閉合狀態拆鏡 |
| 參考條件方式 | 無 / 首幀 / 首尾幀 / 多槽參考（及槽位數上限） | 見下節 |
| 聲音是否同軌生成 | `same_pass` 或 `separate` | 見下節 |
| 畫幅與解析度 | 執行端實際接受的畫幅與解析度集合 | 只寫專案已接受的那一個；不在正文裡羅列備選 |
| 正文長度上限 | 一次能接受的字元數 | 超限時先刪已被真實參考幀承載的重複描述；《視覺設定.md》連續性鎖的鎖面、逐字對白和已批准文字顯示位置不得刪 |
| 運鏡詞彙 | 執行端是否接受具名運鏡術語 | 不接受時把運鏡寫成可見的畫面關係變化（主體佔畫比、邊緣進出、前後景遮擋關係），不是換一個術語 |
| 影片提示詞正文語言 | 目標影片模型本次使用 `zh-CN`、`en` 或其他明確語言 | 影片可複製正文使用該語言；逐字對白、VO、OS 仍保留原口語語言，不翻譯、不加外語開場 |

## 聲音同軌生成

有些執行端只產出畫面，聲音在後期補；有些執行端在同一次生成裡同時產出對白、環境聲與音樂。
兩者對正文的要求不同，應先分清：

- **不同軌**（預設假設）：聲音段落寫本鏡的聲音**職責**——誰說話、什麼環境聲承擔資訊、
  轉場聲落在哪裡。它服務於後期與審查，不需要寫成可執行指令。
- **同軌**：聲音段落直接參與生成。可複製正文須寫出本鏡完整的聲音時間線：需要的
  對白、VO、OS、非語言發聲、SFX 與相對時機，以及各事件之間承接的 ambience 或靜默。逐字對白
  仍按 [交付形態](delivery-profile.md) 的圍欄處理。未定義的時間與通道可能由執行端自行補聲。

有對白、VO 或 OS 時，把本鏡所有允許的發聲列成封閉事件集合，每句帶口語語言和逐字起止邊界，
事件間及首尾明確回到已宣告環境聲或靜默。必要的嘆氣、笑聲、擬聲或重疊也必須有來源並進入集合。
Brief、劇本或聲音方向若已經點名排除外語前導、語氣詞、額外人聲、重複或其他發聲，完整時間線末尾
必須用正文語言把這些已確認邊界合併寫一次；“允許事件只有這些”不能替代模型需要的直接指令。
一句“以上為完整聲音時間線”閉合並結束聲音段落；其後不再重複同一組排除項，也不自行新增上游沒有
提出的聲音禁令。

非畫內字幕、caption 和對白文字疊加是獨立文字層：除非劇本或創作者明確要求，每條可複製正文
都用專案提示詞語言直接宣告全鏡任何時刻不生成這些內容，不能只寫抽象的“文字層為空”，讓對白只
透過聲音與口型發生。這個預設不受畫內文字影響。旗幟、標牌、
螢幕等表面確有 `exact_readable` 義務時，正文逐字保留準確字元、語言、承載面和位置，同時繼續關閉
字幕層；沒有畫內可讀文字義務時，才使用全域性無文字要求（`VID` 與 `IMG` 的文字策略優先順序不變）。

排除條件按本鏡需要和專案提示詞語言表達，不跨專案套用固定字尾，也不據此打分。

## 參考條件方式

| 宣告 | 正文承擔什麼 |
|---|---|
| 無參考 | 文生影片：靜態視覺錨點必須自足，寫清人物、造型、地點、構圖與光線中本鏡必要的事實 |
| 首幀 | 只寫從該起點開始的變化；靜態外觀由參考幀與視覺設定共同擁有 |
| 首尾幀 | 終點幀只能投影 `SHOT-...` 已寫明的終點，不得發明新結果 |
| 多槽參考 | 每張按 `REF-...` 槽位記賬，繫結順序、路徑、中文名、用途與控制/不得控制範圍；槽位數不超過宣告上限，超出時按下面的順序取捨並寫明放棄了哪些 |
| 多槽參考（創作者自備） | 同上，但圖片不在專案裡，槽位改用 `PLAN-...`、定位符寫 `IMG-...` 或 `SHOT-...`；正文寫法與上一行完全相同，`順序` 就是創作者在生成介面裡掛圖的次序。這一行與目標模型無關，任何支援多槽參考的執行端都適用 |

超出槽位上限時，按本鏡失去它的代價從高到低保留：起始幀；正在說話或做主要動作的人物身份；
本鏡必須認得出的道具（交接、證物、持物）；地點或地理；畫面裡但不說話不動作的人物身份；定調圖與
風格圖。先放棄的那些，把必要事實寫進正文和靜態視覺錨點。

無論哪一種，《視覺設定.md》連續性鎖的鎖面都留在正文裡：參考幀只約束它自己畫到的部分，
跨鏡不變的顏色、材質與形制仍然要逐鏡帶走。

**`craft_default`**：只掛身份或地點參考圖、沒有起始幀時，正文寫具體取景：畫面下沿切在哪
（腰、胸口、膝），主體佔畫多高，頭頂落在畫面哪一段，機位高度與離主體多遠。只寫景別名稱不夠，
取景會被地點圖拉寬。一組 H3 小樣本里，只寫「Medium shot」加地點圖的 8 次出了遠景 3、中遠景 3、
中景 2；換成上述取景欄位的 8 次出了中景 7、中遠景 1、沒有遠景。Wan 3.0 一組只寫「雙人中景」的 6 次
也都出成全身遠景（未做無地點圖或取景欄位的對照）。在參考說明裡寫「不繼承它的構圖」本身擋不住這種漂移。有起始幀時構圖由起始幀
承擔，不需要這一步。

參考條件方式由本鏡各槽位的 `用途` 讀出，不由“想不想用多模態”決定：只有一張 `起始幀` 是首幀，
`起始幀` 加 `結束幀` 是首尾幀，`起始幀` 與身份/地理/道具圖同時存在或只有這些圖時是多槽參考。
不少執行端把首/尾幀輸入與多槽參考輸入設為互斥，這時整組統一走多槽參考，起始幀也按參考素材送入——
不要把一次請求拆成“首幀 + 參考圖”。正文裡的素材標籤按同類素材的 `順序` 編號，與生產端繫結順序一致；
文件手寫編號和執行端實際編號不一致時，模型收到的是兩套互相矛盾的素材說明，而介面通常不會報錯。

“上一段實際影片”和“實際尾幀”描述的是兩個通用職責，不等於供應商 role。命中版本化方言時再翻譯：
例如 H3 的 full-reference 使用 `reference_video + reference_image`，不能把實際尾幀誤寫成與參考模式
互斥的 `first_frame`。生產 adapter 必須執行同一翻譯，不能讓文件和請求體使用兩套模式。

## 未宣告時怎麼寫

按已接受的鏡頭邊界寫完整、自足、不依賴任何執行端特性的正文：影片正文語言回退到專案
`format.prompt_language`；獨立任務沒有專案配置時沿用使用者當前語言，不固定為英文。寫聲音職責而不是可執行聲音指令，
不做分段，不羅列畫幅備選，用可見的畫面關係而不是術語描述運鏡。這是未選定目標模型時的通用草稿；選定後仍須按其能力和方言複核。**未宣告不是缺陷**，不能作為審查阻斷理由。

## 自檢

- 每條能力軸的取值是創作者宣告的，還是我推斷的？
- 影片正文語言來自目標模型檔案還是專案回退值？逐字人聲是否仍保留原口語語言？
- 聲音同軌時，允許的聲音事件、口語語言及事件間底聲/靜默是否組成完整時間線？
- 收斂寫法有沒有順手改掉已接受的時長、起點或終點？
- 刪重複描述時，鎖面、逐字對白和已批准文字顯示位置留住了嗎？
