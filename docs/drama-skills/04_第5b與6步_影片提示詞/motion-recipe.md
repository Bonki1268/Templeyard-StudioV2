## 本文負責的規則

- `VID-01` — 把已確認的起點、終點、時長、對白和下一鏡狀態視為只讀內容。
  運動規格只實現這個區間，不能改寫它。
- `VID-02` — 按需填寫起點、有序動作、表演變化、攝影機、環境/聲音和時間，
  最後輸出結束報告。
- `VID-03` — 先區分文生影片與圖生影片。只有真實參考幀已作為輸入時，運動提示詞才可省略它已
  說明的外觀和構圖；沒有真實圖片時必須把靜態視覺錨點寫進可複製正文，不得假設執行端看過分鏡。
- `VID-12` — 補拍版/替代版逐項繫結原文要求，說明本版本沒有承擔哪些內容，
  並明確它是補充母版，還是請求經審查後替代母版；範圍變小不等於完整覆蓋。

## 欄位必須填寫本鏡的具體內容

**`VID-08 · reviewed_invariant`**：每個 `MOTION-...` 條目必須寫出本鏡準確的主體、動作、
接觸和結果；本鏡確有可見表演變化時，再寫承擔變化的演員，不能只放可複製的佔位句。

欄位說明不是鏡頭內容。有序動作要寫本鏡準確的角色繫結、
觸發條件、可見動作、方向/路徑、接觸物件、階段結果和順序。不得在所有鏡頭複製
“已確認主體”“已確認動作”“到達已確認終點”。本鏡有表演變化時，只寫這次
變化真正需要的觸發、處理、選擇或落點，不為欄位齊全複製一套固定步驟。

判斷方法：若一條運動說明原樣複製到下一鏡仍然成立，它多半沒有寫出本鏡的具體內容。
把內容換成本鏡事實，並刪掉無關物件和動作。

### 選擇性變換邊界

**`VID-11 · reviewed_invariant`**：當一段運動只讓環境或主體的一部分摺疊、消失、
替換、破碎、復原或改變形態時，必須寫清：

1. **觸發**：哪個已確認的動作、狀態或聲音開始變換；
2. **目標範圍**：精確到哪一個人、物、表面、空間構件或區域性，沿什麼路徑變化；
3. **結束幾何/狀態**：變換後留下、佔據或暴露什麼，不只寫“消失了”；
4. **保持項 `preserve_set`**：同框但不參與變換的人物、手持道具、文字所在表面和空間錨點，
   要保持什麼位置、數量和連續性狀態。

這需要審查內容是否正確、動作是否能執行，不能靠關鍵詞檢查證明。若目標模型會把鄰近物一起
吞掉，先縮小目標範圍、拆成多個運動階段或增加階段邊界；不要只堆“其他不變”之類空泛的負面詞。

### 參考圖用途與補拍範圍

每張參考宣告準確的穩定 `REF-...` 槽位、順序、專案相對路徑、中文名稱、用途、允許控制、不得控制與觀察狀態，
且影片文件必須與分鏡原文一致。起始幀可以決定本鏡起始構圖和
可見狀態，卻不能
提供尚未發生的終點；構圖、尺度、效果參考也不能帶入圖中沒有來源的人物、文字、
道具或事件。只有創作者/參考圖權利人的可核對說明，或執行環境獲授權後形成的準確
觀察說明才能支援畫素/文字結論；只有文字引用時保持“未驗證”。

**`VID-12 · reviewed_invariant`**：普通母版不寫覆蓋清單；只有區域性補拍或替代實現才在同一
`MOTION-...` 章節下寫“版本關係”。同一 `SHOT-...` 只保留一個正式 `MOTION-...` 及一份可複製正文，
候選差異寫在普通說明中；需要獨立補拍鏡頭時，先交分鏡新增對應 `SHOT-...`，再寫匹配的 `MOTION-...`。
用已有標題指明母版與補拍，逐項列出動作、反應、對白、揭示、
結束邊界和專案要求由本版本、母版、另一補拍承擔，還是必須退回分鏡。運動提示詞只能提出替代；
reviewer 結合完整故事義務決定，不能讓未承擔內容隨更短提示詞消失。

## 1. 目的、輸入與權屬

影片提示詞把已確認鏡頭的變化寫成能按時間執行的過程。
輸入包括：鏡頭與關鍵幀、準確的資產引用、時長、鏡頭目的、起止邊界、對白、畫外音、音效和聲音引用、
進出連續性、視覺/聲音方向和可選的製作能力配置。

分鏡負責地點/時間、資產版本、構圖意圖、時長、對白、起止姿態/位置/目光/雙手/持物、
連續性終點和下一鏡起點。運動規格對這些內容只讀，只能報告當前描述是否到達要求的終點。

### 最少但夠用的起點資訊

只重複“開始運動必須知道”的狀態：

- 重心在哪隻腳、身體面向和是否坐/倚/跪；
- 目光落點與注意物件；
- 雙手的位置、哪隻手持什麼、接觸是否已發生；
- 與門、桌、人等行動相關物件的距離/方位；
- 正在持續的運動（若關鍵幀凍結的是運動中瞬間）。

真實參考幀已作為輸入幷包含臉、服裝全貌、牆面材料等內容時不重複。**`craft_default`** 是“圖生影片
只重述動作所需條件，不重述整份視覺設定”。文生影片沒有這種省略資格，必須提供足以獨立建立本鏡
人物、造型、地點、構圖與光線的靜態視覺錨點；若提示詞離開參考幀會把左右手或物體搞錯，圖生影片
也應保留這些區域性事實。沒有起始幀、只掛身份或地點圖時也沒有這種省略資格：取景要寫具體，見
[目標模型能力檔案](target-model-profile.md#參考條件方式)。

## 3. 運動說明的七個部分

### 3.1 起點

用現在時、靜態句準確寫出起點，避免“她準備站起來”這種已經加入未來動作的寫法。
若關鍵幀與鏡頭起點不一致，先請求分鏡環節解決，不能任選其一。

### 3.2 有序動作

每個動作階段說明：誰行動、做什麼、方向/路徑、物件/接觸、先後條件和到達狀態。優先按因果關係連線：

```text
聽見門外金屬碰響後 → 目光先移向門縫 → 左手停止翻頁並壓住記錄本 → 身體才從椅背離開
```

而非：

```text
她轉頭、翻書、站起、走向門、微笑、震驚，所有動作同時自然發生
```

“緩緩、自然、電影感”不能替代路徑與結果。只描述畫面內可見動作；心理詞要落為呼吸、
注視、肌肉張力、停頓、話語節奏或明確的畫外音。

先把起點中的持續關係翻譯成動作自由度：用正向狀態寫清貫穿本鏡的支撐、固定、接觸或空間關係，
再只安排允許的身體/物件通道。關係變化必須來自已接受動作並落到已接受終點；否則按 `VID-01`
保持只讀。可複製正文寫清持續狀態和允許動作，避免重複約束；必要的排除條件可以保留。
成稿時檢查否定條件是否必要，並把可由持續狀態直接說明的部分改為正向描述。

**`craft_default`**：一條運動提示詞優先只有一個主導的戲劇變化，必要反應、環境與攝影
都服務這項變化；這不是固定動作數量。若同一鏡必須同時完成互不依賴的交接、追逐、身份
揭示和大範圍效果，先向分鏡負責技能請求按注意轉移或動作銜接拆鏡。反過來，也不能為了變短
刪掉逐字對白、關鍵反應或終點義務；短與長都不是品質指標，可執行的因果路徑才是。

若該動作包含選擇性變換，按 `VID-11` 把觸發、目標範圍、結束幾何/狀態和 `preserve_set`
寫進相應動作階段；不能讓相鄰非目標人物、道具或已批准文字跟隨目標一起改變。

### 3.3 表演過程

表演不是表情標籤序列。找到最小變化：

1. **觸發**：外部聲音/動作/台詞或內部決定（來源可追溯）；
2. **接收**：注意被什麼抓住；
3. **處理**：一個讀得出的訊號，而非面部部件清單；外放到什麼程度見下文的表演強度；
4. **決定**：角色採取/抑制什麼行動；
5. **結果**：到達已確認終點的情緒與身體狀態。

- **`craft_default`**：把副詞換成節奏和行為，“憤怒地說”可具體為先壓低音量、吞回半句話、最後直呼對方全名——前提是符合台詞與人物。
- **`reviewed_invariant`**：不能發明新資訊、關係轉變或角色意圖。審查者對照鏡頭目的和劇本資料判斷。
- **`taste_option`**：強度與外顯程度可從剋制到爆發，由導演選擇，不強制“先微表情後爆發”。
- **`craft_default · VID-26`**：沒有導演選擇時，表演強度跟隨製作形態與題材。漫劇和爽文的峰值，關鍵姿態和表情
  外放：表情變化大到一眼讀得出，手勢用整條手臂，情緒落在上身和整張臉上，仍按[可生成性](generability.md)寫成
  常見的整體動作，劇情不壓在微表情上。AI 真人劇保持生活化的剋制，但峰值也要有一個讀得出的表演拍，例如一次
  明顯的變臉、一次猛地停住或轉身，不讓整集只剩靜臉。形態讀 `視覺設定.md` 的製作形態，或已接受節奏檔案的 `form`。

### 3.4 攝影機

選擇有明確目的的固定機位或一條主要運動路徑。移動機位要寫動機、開始條件、運動方向/速度和
終點景別；例如“當信封被推入光區時，機位做一次短促前移，停在手與印章的近景”，
比“鏡頭電影感推進”更清楚。詳見 `camera-audio-continuity.md`。

### 3.5 環境與聲音

只讓環境中對故事或連續性有意義的元素動：風推動窗簾、遠處警示燈掃過牆、杯中水因桌面撞擊晃動。
不要給每個背景物同時加動作。聲音部分引用準確的對白、畫外音和音效，說明表演方式、同步要求、
空間聲源和層級，不改台詞。

目標執行端同軌生成聲音時，把音訊寫成一個完整時間線：

1. 按發生順序列出本鏡全部對白、VO、OS、必要非語言發聲和 SFX；
2. 每條台詞同時標說話人、聲源性質、口語語言和逐字文字，發聲從原文首字開始、到末字結束；
3. 所列事件之外只保留已宣告的 ambience 或靜默；相鄰兩句之間若有停頓，也明確回到這一底聲；
4. 用實際存在的聲音層總結時間線，避免模板與本鏡內容矛盾。

無對白鏡寫清底聲或靜默及覆蓋區間。必要的「無對白」宣告可以保留，
人物嘴部狀態由本鏡表演決定。非畫內配樂的空形式按目標方言填寫。

確有嘆氣、吸氣、笑聲或重疊說話時，把它作為有來源的事件列入。聲音不同軌時仍只寫後期職責。

### 3.6 時間

預設把這幾秒寫成一條讀得出先後的節拍鏈：

```text
首先<起手狀態>；接著<動作、方向與終點接觸>；隨後<這個動作造成的結果>；與此同時<另一條通道>；最終<結束狀態>
```

- **動作停在哪裡，用接觸點或畫面裡的地標寫**。“指尖碰到杯沿後停住”“視線落到桌面簽名處”
  “右手停在傘柄上”說的是本鏡要拍成什麼樣，直接寫，不必等上游先給數字。釐米和度數不寫：
  H3 一鏡的小樣本里，寫「約二十釐米後停住」的 4 次中 3 次仍伸到杯子並接觸，
  寫「指尖碰到杯沿後停住」的 4 次全部停在杯沿。寫不出終點接觸什麼、停在哪個地標，
  通常說明這一拍還沒想清楚——先把動作想清楚，再回來寫這一句。
- **可以釘一到兩個錨點秒數**：起手保持多久、終點定格多久、一次運鏡走多久（“起手不動約半秒”
  “結束姿態定住約一秒”）。錨點是正文中的散文標註，不單獨拆成顯式分段，不參與 `VID-04` 分段求和。所有錨點相加應當明顯小於鏡頭時長，鏈條其餘
  部分留給相對先後；錨點多到要鋪滿整鏡時，改寫成下面的顯式分段。
- **並行通道由“與此同時”顯式標出，一條鏈只給一條**，且落在序列鏈沒佔用的通道上：另一個
  角色、主體的另一處身體通道，或環境。同一隻手、同一道視線不能同時走兩條。

只有製作需要按秒對齊時才寫顯式秒段。

- **`structural_invariant`**：明確標註的非重疊段落時長相加必須**等於**已接受的鏡頭時長；重疊段必須寫明重疊關係，而不是靠猜。
  - **超出**：落在時長之外的部分被截斷，段尾動作、逐字對白和終點姿態一起丟失。
  - **不足同樣是缺陷**：執行端可能不停在最後一段的秒點上，而是把已寫的動作整體拉長去佔滿鏡頭，寫下的秒點於是整體後移，計劃裡的時間就不再描述成片。H3 一個 8 秒單人鏡的小樣本里，秒段只寫到 5 秒、補「定住終點」到 8 秒、只寫相對順序三種寫法各 4 次，都沒有出現計劃外動作；三種寫法的放杯都落在 6–7 秒，補寫的 3 秒定格也沒有出現。把餘量分配給已有階段，讓寫下的節奏與鏡長一致；秒點只是計劃記賬，不是精確落點，需要按秒剪輯或對齊時以生成結果的實測為準，落幅保持靠剪輯餘量而不是一段定格描述。
  - 兩個方向都由 `VID-04` 管轄；審查者引用該編號時，超出與不足都算違約。
- **`reviewed_invariant`**：即使數學不超時，台詞、動作、反應是否可完成仍由審查者結合語言、強度和物理路徑判斷。
- 不設通用“每秒幾字/幾個動作”硬門檻。

在同一 `MOTION-...` 條目寫顯式秒段時核對三件事：

| 檢查項 | 含義 |
|---|---|
| 計時方式 | 明確寫出各段起止時間才按顯式分段求和；只寫相對先後時，不聲稱已經按秒對齊 |
| 重疊關係 | 區間確需重疊時寫明，實際佔用時間按並集計算，不能預設逐段相加 |
| 計時範圍 | 總佔用時長與最後終點分別核對，避免空檔與超出互相抵消 |

超出按**終點**判斷，不足按裁剪到鏡頭長度內的**並集**判斷。兩者分開量是因為中間留空加尾部超出會互相抵消——
`0.0-2.0` 加 `3.0-5.0` 在 4 秒鏡頭上"合計正好 4 秒"，實際卻同時發生了截斷與留白。

### 3.7 終點核對

在同一 `MOTION-...` 條目核對姿態、位置、目光、雙手、持物和可見狀態變化。
逐項對照分鏡的「終點」：

```text
reported_end == source end：match
reported_end 不同：mismatch + 請求修改分鏡
提示詞未實現某欄位：unrealized + 修改運動說明
```

本鏡的終點核對說明不是下一鏡的權威輸入。不能用運動規格中的“更自然結尾”覆蓋已確認終點。

## 4. 從鏡頭事實到自然語言

### 可複製的寫法骨架

```text
從[最少但夠用的起點資訊]開始。首先[起手狀態，可含一個錨點秒數]；接著[動作、方向與終點接觸]；
隨後[這個動作造成的結果與隨之而來的可見處理]；與此同時[另一條通道上並行的一件事]；
最終[已確認終點的可見狀態]。攝影機[寫死構圖並說明保持多久，或一次有動機的移動，含觸發、路徑與終點景別]。
[必要的環境運動]。對白/聲音：[準確來源與表演/空間意圖]。
```

### 寫完之後過一遍可執行檢查

檢查執行端能否從正文讀出本鏡必要的起點、先後、邊界與終點。只補本鏡實際需要的內容：

| 必須寫出來 | 缺了會發生什麼 |
|---|---|
| 起手狀態（這一拍從哪個姿態開始） | 執行端自選起點，接不上前一鏡的終點 |
| 序列鏈：接著→隨後，每一步帶方向，終點落到接觸點或地標 | 動作糊成一團，看不出先後，也不知道停在哪 |
| 確有並行動作時，用「與此同時」標出其通道 | 並行關係不明，可能被誤讀為序列或全員同時動作 |
| 結束狀態（終點姿態定在哪） | 收尾被自由發揮，下一鏡起點失效 |
| 攝影機：鎖定寫死構圖與保持多久，移動寫觸發、路徑、終點景別；兩種都補一句**這次要讓觀眾看清什麼** | 空著會被讀成可以自由漂移；沒有理由的運鏡是裝飾，執行端換一種也說得通，於是真換 |
| 有台詞時把台詞逐字掛在它發生的那一拍上 | 口型對不上，或台詞被當成畫面內容渲染 |

**`craft_default`：刪重複，不按字數裁剪。** 將景別、機位、角度和焦段合進一句，
例如「固定中近景，軸線左側平視，中焦」；確有並行動作時，把它接在實際發生的那一拍後面。
優先刪除重複外觀、同一動作的換詞複述和不能指導表演的解釋，保留台詞掛載、聲音、
起止條件與連續性鎖面。正文長度由本鏡內容和目標模型上限決定。

以下合成片段示意動作鏈、並行通道和攝影機的組織方式；其中從壓膝姿態到站直的起身過程仍需補足，
不能照抄為完整終稿：

```text
從她雙手交疊壓膝、視線在腳邊水窪的起點開始。首先保持不動約半秒；接著右手離膝向傘柄
伸出，指節碰到傘柄；隨後扣住傘柄，把傘立起點在地面；與此同時水窪被風推出一層細紋；
最終她站直，右手持傘垂在身側，視線抬到對面門口。攝影機固定，平視，取頭肩，軸線左側，
全程不動——讓觀眾看清她起身前後手上的變化，而不是跟著她走。台詞在「接著」這一拍：「我不等了。」
```

把後設資料、`hash`、內部規則 ID 留在 Markdown 卡片，不放進可複製提示詞。避免供應商引數、權重語法、任務指令和品質承諾。
參考圖檔名、版本號、鎖定標記、草圖指代和重投備註同樣留在正文外，避免與生成內容混淆；完整清單與改寫方法見
[production-prompt-grammar.md](production-prompt-grammar.md) 的“交付文字只含交付內容”。若專案宣告瞭分段交付檔案，容器算術與槽位職責見
[delivery-profile.md](delivery-profile.md)。

### 不重複參考幀內容

- 參考幀已經表達：人物長相、整套服裝、空間裝修、靜態構圖、基礎光線；通常省略。
- 運動說明仍需表達：左右手/持物、即將行動的關節與路徑、目光目標、運動相關遮擋、會變化的環境和鏡頭運動。
- 能刪去而不改變動作結果的外觀句，優先刪。
- **`craft_default`** 不是“越短越好”；關鍵起止條件不能因為節省字數而丟失。

## 5. 輸出、常見問題與檢查

### 輸出

- 已接受的運動規格：有序動作、表演、攝影機、環境、聲音和時間；
- 起點/終點的只讀來源引用與結束比較報告；
- 一段可複製的通用提示詞，以及必要的警告或內容丟失說明；
- 不含影片、音訊、遠端任務 ID、網址或介面狀態。

### 常見問題

- 從不同於關鍵幀的手勢或持物開始；
- 提示詞大半重寫人物服裝和場景，動作只剩“自然移動”；
- 所有動作“同時”，接觸/方向/先後不明；
- 選擇性變換隻寫“消失/變形”，沒有目標範圍、結束幾何或 `preserve_set`；
- 表演只有“震驚—生氣—悲傷”標籤，沒有觸發和可見過程；
- 終點新造了站位、道具轉移或下一鏡事實；
- 單個鏡頭內部出現未宣告的剪下（多鏡容器在成員鏡頭邊界上的切換不算，見
  [delivery-profile.md](delivery-profile.md) 的多鏡容器）；
- 明確時間段只用掉時長的一部分，剩下的秒數沒有任何內容承接；
- 交付文字里混入檔名、版本號、鎖定標記或重投備註。

### 檢查

1. **結構**：來源引用、時長、明確時間段、攝影機區間、對白引用和結束比較。
2. **內容**：審查者引用鏡頭與運動說明，判斷能否執行、能否表演、攝影動機是否成立、是否發明內容。
3. **常用做法**：動作精簡、避免重複參考幀、單一主運鏡都可以建議，但允許有理由地調整。
4. **創作者選擇**：表演強度、固定/移動機位、節奏和聲音密度由已接受的創作方向決定。
