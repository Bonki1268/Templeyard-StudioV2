# Wan 3.0 提示詞方言

只在目標檔案明確寫 `target_video_model: wan-3.0` 時使用。推薦檔案：

```json
{
  "target_video_model": "wan-3.0",
  "video_prompt_dialect": "wan-3.0",
  "video_prompt_language": "zh-CN",
  "native_duration_seconds": {"min": 2, "max": 30},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference"],
  "audio_generation": "same_pass"
}
```

Wan 3.0 用中文自然指令，素材寫成 `圖1`、`影片1`、`音訊1`。它和 Seedance 一樣讀中文長句，
但素材標記、多鏡時間段和對白寫法都不同，不套用 Seedance 的 `@圖片N`、`{…}` 或 `<聲音>`。

## 選哪一種模式

| 本鏡繫結的圖 | Wan 3.0 模式 | 正文怎麼指代 |
|---|---|---|
| 沒有圖，且創作者已明確選擇文生影片 | 文生 | 靜態視覺錨點寫進正文，不出現素材標記 |
| 只有一張 `用途：起始幀` | 首幀 | 從輸入幀的可見姿態寫起，不另起標記 |
| 一張 `用途：起始幀` + 一張 `用途：結束幀` | 首尾幀 | 終點只投影分鏡已接受的終點 |
| 其他任何組合 | 參考 | `圖N` 逐張點名職責 |

首幀、尾幀與 `reference_image`、`reference_video`、`reference_audio` 在同一請求裡**互斥**。
「起始幀 + 角色圖 + 場景圖」整組走參考模式，起始幀也作為參考圖送入，正文寫
「圖1 是本鏡開場畫面」，不拆成首幀加參考圖。沒有起始幀、只掛身份或地點圖時寫具體取景，見
[目標模型能力檔案](target-model-profile.md#參考條件方式)。首幀與首尾幀模式本套件未實測。

## 素材編號與上限

`圖N`、`影片N`、`音訊N` 各自從 1 開始，按同類素材在請求陣列裡的次序編號，也就是本鏡
「輸入參考圖」裡的 `順序`。每次使用都寫清這張圖負責什麼：「圖1 中的年輕女子站在圖2 的舊書店裡」，
不讓一張圖順帶決定身份、構圖和動作。

一次最多 10 張參考圖、5 段參考影片、5 段參考音訊；影片與音訊每段 1–15 秒，各自合計不超過 15 秒。
首幀、尾幀各 1 張。正文不超過 20000 字元。超過上限時在分鏡階段按重要性取捨，並寫明放棄了哪些參考。

## 時長

`duration` 為 2–30 的整數秒；帶影片輸入時，輸入影片時長加輸出時長不超過 30 秒。`-1` 是智慧時長，
由模型自己選。固定時長交付顯式傳分鏡已接受的秒數，不把規劃鏡長寫成自動時長下已經保證的輸出長度。
解析度可選 1080P、720P、480P，畫幅按專案已接受的那一個傳。

## 多鏡時間段

多鏡按 `(0:00 - 0:03) 鏡頭1，遠景：…` 寫時間段，段與段首尾相接，最後一段終點等於總時長。

幾個相鄰鏡頭裝進一次生成、每切掛自己的已接受關鍵幀時，先寫一句「圖1、圖2、圖3 依次是三個鏡頭的
畫面，圖4 是老人，圖5 是年輕女子」，再在各段裡寫「按圖N構圖」。成員資格與容器算術按
[交付形態](delivery-profile.md) 的多鏡容器記賬，關鍵幀按切的順序排在參考清單前面。

這種寫法可用，但切點不準。一組 9 秒三切的小樣本（要求 3.0/6.0 秒切）3 次：切點落在 2.46–3.46 /
4.92–6.17 秒，第三切與關鍵幀的構圖相似度也明顯低於前兩切。需要準確切點的交付逐鏡生成，
或者生成後按實際切點剪輯。

## 對白與語速

- 對白寫成 `說道：“逐字台詞”`，用中文引號，跟在說話人的可見動作後面：
  「她望著鏡頭，聲音輕而穩，用普通話說道：“……”」。這是官方示例的寫法。花括號
  `{年輕女子用中文說：“……”}` 在小樣本里同樣逐字完整、括號裡的說明沒有被念出來，但不作為本方言寫法。
- 語速按 [對白預算](performance-action-timing.md#對白預算) 先估再排時。Wan 3.0 中文小樣本約
  4.6 個可發聲字/秒：21 字配 5 秒、41 字配 10 秒都以常速說完。41 字塞進 5 秒仍說完，但趕到
  8.2–8.7 字/秒；66 字塞進 5 秒時只說出前 21–24 字，其餘靜默丟掉，介面不報錯。所以超出容量時
  看不到失敗提示，生成後逐字核對台詞是否說完。
- 說話人的聲音要跟參考音訊走時，寫「圖1 中的女子說話時，音色參考音訊1」。實測掛一段該角色另一句話的合成做參考，
  兩個角色 9 鏡的聲音都明顯靠向參考，口型與不掛參考時接近；這是跨鏡保持角色音色的預設做法。
- 把這句台詞本身的合成掛成音訊1、寫「口型與音訊1 逐字同步」時，生成的人聲幾乎就是這段音訊，音色最穩；
  代價是口型略差（句中停住、提前張嘴更常見）。音色必須一致時用它，生成後逐鏡看口型。
- 雙人鏡裡不說話的人按 [對白、口型與聲音](camera-audio-continuity.md#精確引用) 的順序處理；Wan 3.0 的
  小樣本太小，寫不寫「他不說話、嘴唇閉合」沒有看出差別。

## 聲音與文字

寫全本鏡聲景：環境底聲、每個音效事件及其時機，並單獨寫一句配樂層——需要配樂就寫情緒與進出，
不需要就寫「無背景音樂」。一組小樣本里寫全環境聲、不提配樂與加「無背景音樂」各 4 次，
8 次都沒有配樂；仍把配樂層寫明，不留給模型決定。

預設禁字幕時寫「全程無字幕，不生成對白文字疊加」；畫內獲准文字仍逐字說明承載面和位置。
只有本鏡沒有畫內可讀文字義務時，才加全域性無文字要求。

## 智慧改寫

官方 API 的 `prompt_extend` 預設 `true`，會先用大模型改寫提示詞再生成。已審過的正文可能被改掉逐字
台詞、聲音層或鏡頭數。直接呼叫 API 時顯式傳這個引數；所用平臺不暴露它時，預設它在改寫，
生成後對照正文核對台詞、聲音層與切數。

## 編輯與延長

編輯和延長都是「`reference_video` + 寫明意圖的正文」，沒有單獨的任務型別欄位，所以不寫
Seedance 2.5 的「任務型別」一行：

- 編輯：「編輯影片，把影片1 中……改成……」，或用「去掉」「替換」「改成」點名要改的那一處，
  其餘照原片保留。
- 延長：「將影片1 向後延長 N 秒」「延續」，或「向前延長」；需要 `ratio: adaptive`。
  從輸入影片的實際終點寫唯一動作和新終點，預算的是新增片段的時長與對白。

連續段需要上一段實際影片和實際尾幀時，因為首幀與參考互斥，兩者都走參考模式：影片為 `影片1`，
控制動作、節奏和聲音連續；尾幀為 `圖1`，只控制新段開場的可見姿態與構圖。
