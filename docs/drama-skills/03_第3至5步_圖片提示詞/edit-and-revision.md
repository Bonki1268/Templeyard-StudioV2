# Scoped Edit 與自然語言修訂

## 有界編輯合同 (`IMG-06`)

每次區域性編輯都宣告準確目標和區域、變化、保持項及預期連續性影響。如果期望變更會
改寫身份或已確認上游事實，交回負責該事實的技能，不要偽裝成區域性提示詞修訂。

## 目錄

1. 兩類修改

## 1. 兩類修改

- **對畫面目標的 edit**：產出 `edit_delta` 提示詞，例如改變一件衣服區域性狀態；不執行影象編輯。
- **對提示詞本身的 revision**：創作者用自然語言修改當前 `IMG-...` 條目；先展示差異，接受後更新可複製正文。

二者都不能改寫 assets 擁有的身份/variant 事實。若請求是“把這扇門移到另一面牆”而地點地理尚未變更，先向資產負責技能提出修訂，再請分鏡核對受影響鏡頭；不能只改區域性編輯提示詞。

## 2. Edit-delta 配方

四個問題缺一不可：

```text
Target：哪個可見 `IMG-...`、物件和區域？
Change：哪些有邊界、可觀察的變化？
Preserve：身份、構圖、光線、空間以及哪些未影響 entity/region 必須不變？
Continuity impact：預期對應哪個已確認狀態或引用，有效到哪裡？
```

### Target

- 元資訊用準確 `IMG-...` 定位提示詞條目；實際待編輯圖片另用 `REF-...` 繫結。未提供圖片時說明缺口，
  保留修改意圖，不聲稱已檢查圖片。可複製正文用自然語言明確主體和區域。
- “改背景”“讓她更狼狽”過寬；需要具體新 View/區域與可觀察變化。
- 多個不相干 target 預設拆為多個 edit，防止 preserve 集失焦。

### Change

按位置、方向、範圍、程度、材質/色彩結果寫 delta。例如“右袖肘部以下呈雨水浸溼後的深色，衣料貼合但無撕裂”，比“衣服弄溼”可控。不得補寫未接受的傷勢或劇情因果。

### Preserve

先列最容易被誤改的高價值事實：面部/體態身份、未變 Look 部件、固定地理、道具輪廓與文字、構圖/機位、光向、未選區域。不要寫“其他全部保持”代替邊界思考；允許最後用它概括已經點名的 preserve set。

### Continuity impact

引用道具狀態、造型或觀察視角，必要時向其負責技能提出修訂；記錄受影響的圖片提示詞、鏡頭或關鍵幀，而非在 edit 中成為新的連續性權威。若沒有影響，也明確 `none` 及理由。

- **`structural_invariant`**：目標、區域、變化、保持項和影響必須存在且沒有顯式衝突。
- **`reviewed_invariant`**：修改範圍是否足夠清楚、preserve 是否保護真正身份/地理，需要審查者引用證據判斷。
- **`craft_default`**：一次 edit 聚焦少量相互關聯的 delta；複雜重構改用新 variant/plate。
- **`taste_option`**：變化的視覺強度由創作者決定，只要狀態事實未變。

## 3. 自然語言修訂

使用者不需要知道內部欄位。對“把工作服換成深藍，但保留臉和袖口油漬”執行：

1. 讀取當前 `視覺設定.md` 條目和 `圖片提示詞.md` 的 `IMG-...`；
2. 區分提示詞可改措辭、資產負責技能才能改的事實、含糊項和連續性影響；
3. 展示簡短語義差異：改前、改後、理由、保持項、影響和是否需要上游修改；
4. 展示新的可複製正文，讓創作者看到實際效果；
5. 確認後直接更新同一個 `IMG-...`；拒絕時當前檔案保持不變；
6. 列出需要同步檢查的 `SHOT-...` 或其他 `IMG-...`，不自動改使用者未點名的文件。

建議預覽：

```markdown
### 提議修改 `IMG-...`
- 深灰藍工作服 → 深藍工作服
- 保持：臉、服裝剪裁、右袖口舊油漬的形狀與位置、背景、構圖、光向
- 影響：僅當前造型提示詞；若 `視覺設定.md` 還沒有深藍變體，先交給 assets 修改

**新正文預覽**
> ...
```

對“更有電影感”不能擅自堆一串風格詞。給兩三個互斥且可觀察的候選，例如光比、構圖或色彩關係，
作為 `taste_option` 讓創作者選擇。

## 4. 當前檔案衝突

如果另一個編輯或人工修改已經改變當前 `IMG-...`，不要用舊預覽覆蓋：

- 重新讀取當前條目；
- 展示人工改動與本次修改的語義差異；
- 能安全合併時生成新的完整預覽；
- 無法無損對應、觸及上游事實或存在衝突時保留當前檔案，並交給創作者選擇。

不得把“最後寫入者獲勝”當創作規則，也不得為了恢復格式丟掉人工增加的有效語義。

## 5. 失敗與檢查

### 失敗徵兆

- 只改可複製正文，卻不核對 `視覺設定.md`；
- 差異只寫“最佳化措辭”，沒有語義影響和保持項；
- 把身份、地點地理或道具狀態在提示詞層擅自改掉；
- edit 只有 Change，沒有 Preserve；
- 發現衝突後自動覆蓋人工修改。

### 完成檢查

- 上游事實請求已交給正確負責技能；
- 目標、區域、變化、保持項和連續性影響都清楚；
- 差異預覽可讀、可拒絕，新正文可直接複製；
- 拒絕不改變當前檔案，衝突不靜默吞掉；
- 本流程不呼叫媒體生成或 provider API；實際生產交 `$short-drama-produce`，並對精確任務預覽單獨確認。
