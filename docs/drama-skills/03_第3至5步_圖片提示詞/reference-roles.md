# 一張參考圖可以決定什麼

繫結參考圖等於告訴下游“哪些地方照著它”。不說明邊界，身份參考會越權決定服裝、構圖、背景或文字。

## 每張參考回答五個問題

1. 它的穩定槽位和顯式順序是什麼：專案內圖片用 `REF-...`，專案外由創作者自行掛載的圖用 `PLAN-...`；
2. 它的可見定位符和中文名稱是什麼：圖片在專案裡時寫專案相對路徑，例如
   `輸入/參考圖/許棠定妝.jpg《許棠定妝照》`；圖片由創作者在專案外準備並在生成時自行掛載時，
   寫它對應的 `IMG-...` 板子或 `SHOT-...` 凍結關鍵幀；
3. 本次參考身份、造型狀態、地理、構圖、尺度、效果、起始幀、結束幀還是風格；
4. 哪些可見內容允許照著寫；
5. 哪些身份、文字、人數、道具和空間錨點不能跟著變。

分鏡與影片的「輸入參考圖」可用上述兩種槽位；圖片提示詞的「參考」欄位只使用真實 `REF-...`，
沒有真實參考時宣告無外部參考。第 3 問對應槽位的 `用途` 欄位，取值只能是下表左列的九個詞之一。
它同時回答創作者的「這一鏡要送哪一張分鏡起始幀、哪些人物/道具/場景圖」，和執行端的「這張圖翻成哪個
供應商 role」。同一張圖承擔兩個作用時分開成兩個槽位，不寫“全參考”。

| 用途 | 可以控制 | 預設不能控制 |
|---|---|---|
| 身份 | 穩定臉型、體態、識別標記 | 臨時服裝、姿勢、場景、文字 |
| 造型狀態 | 已決定的服裝、傷損、溼汙 | 新身份、無來源道具、背景方位 |
| 地理 | 入口、區域、固定錨點、方向關係 | 臨時人物、劇情狀態 |
| 構圖 | 佔畫比例、視線佈局、鏡頭一側、留白 | 人物身份、服裝、道具文字 |
| 尺度 | 主體之間或主體與環境的相對尺度 | 風格、身份、數量、動作結果 |
| 效果 | 已決定效果的形態、範圍、材質 | 非目標物件的消失、複製或變形 |
| 起始幀 | 本鏡起始構圖與狀態 | 尚未發生的動作和終態 |
| 結束幀 | 本鏡明確終點 | 新終點或未由鏡頭承擔的結果 |
| 風格 | 色彩層級、材質、陰影邊緣、景深、密度 | 身份、固定地理、劇情、道具文字 |

`身份` 和 `造型狀態` 的界線是「本集之內會不會變」，不是「算不算衣服」。一張角色板同時固定長相和
本集從頭到尾不變的造型時，寫一個 `身份` 槽位，並把 `本集造型` 明確列進 `控制`——這是本套件的既定寫法。
只有在本集之內會改變的狀態（換裝、溼透、破損、血汙）才另開 `造型狀態` 槽位，讓它管那一次改變。
判斷依據永遠是這個槽位自己寫下的 `控制` 範圍，不是用途名稱的字面意思。

道具板落在 `身份` 還是 `造型狀態`，按這張圖決定的是「它是哪一件」還是「它此刻處在哪個狀態」：
固定的形制、配色、裂紋與磕角這類跨鏡不變的識別標記寫 `身份`；亮屏/熄屏、開合、溼汙、破損程度
這類會隨劇情改變的寫 `造型狀態`。同一件道具的兩者都需要固定時，拆成兩個槽位。

## 觀察邊界

創作者或權利人給出的可核對說明可以作為文字證據；執行環境獲授權看過參考圖時，可以報告實際可見
內容。兩者都沒有時保持“未驗證”，不得聲稱水印、文字、裁切或身份已經透過。負面提示詞不能擦掉
參考圖已有的畫素。

真實參考圖使用 `REF-...` 穩定槽位，不使用 `IMG-...`；後一字首專屬《圖片提示詞.md》的可見提示詞標題。
創作者自己掛載的圖使用 `PLAN-...` 槽位，語法與 `REF-...` 相同，只把路徑換成它對應的 `IMG-...` 或
`SHOT-...` 條目——這五個問題的答案一個不少，只是第 2 問答的是「這張圖畫的是哪一條已決定的事實」，
而不是「檔案在哪裡」。上表九個用途對兩種槽位同樣適用。每張真實圖分別寫明槽位、順序、路徑、中文名、用途與控制邊界；
聯絡表只用於瀏覽，不改變每張圖的用途。幀參考預設只使用起點；
確實需要終點幀時，它只能投影 `SHOT-...` 已寫明的終點，不能自行發明結果。

[補拍與替代](pickup-and-alternate.md)。
