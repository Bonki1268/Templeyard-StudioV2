# 場景空鏡與地理保持

## 地理測試 (`IMG-04`)

場景空鏡保持已接受的佈局、方向、固定錨點、材質與光向。
預設不帶角色，以保持作為地理參考的複用性；只在創作者明確需要尺度參照
或已接受的場景佔用狀態時加人。

## 目錄

1. 目的與輸入
2. Location 與 View
3. 地理優先的編寫法
4. 光線、氣氛與空場
5. 輸出與審查
6. 製作形態投影

## 1. 目的與輸入

地點板讓後續鏡頭共享同一方位清楚的空間。輸入包括已接受的地點、一個準確觀察視角及時間天氣狀態、固定錨點、材質與視覺風格、空場政策、光向及來源指標。

**`reviewed_invariant`**：提示詞必須保持場景的地理、方向、固定錨點及其相對關係。裝飾豐富不能補救門窗移位或尺度不明。

## 2. Location 與 View

- **Location** 擁有不會隨鏡頭輕易變化的邊界、入口、功能區、固定結構和關鍵材質。
- **View** 選擇觀察方向、可見區塊、區域性陳設、時間/天氣/燈光狀態；它不是隨意重建 Location。
- 鏡頭焦段、機位高低或畫幅通常屬於構圖選擇，不足以單獨成為新 Location。若一個角度顯示不同側，需要 View 而非新場景。

先畫“文字地圖”：從哪個入口看向哪個方向，必要的前中後景分別是什麼，關鍵錨點在彼此哪一側，演員可能從哪裡進出。只有與識別、排程或連續性有關的結構進入 prompt。

## 3. 地理優先的編寫法

### 必要層次

1. **身份與功能**：這是什麼空間，服務什麼活動，整體尺度。
2. **View 與方向**：觀察位置、朝向、可見邊界；必要時給左右以畫面/場內參照，避免“左邊”含義漂移。
3. **入口與路線**：門、走廊、樓梯、通道在哪裡，彼此如何連線。
4. **固定錨點**：櫃檯、柱、窗、機器、壁爐等不可移動物及相對關係。
5. **材料與色彩**：對辨認結構有用的牆地頂、磨損和主次色。
6. **當前 state**：擺設、天氣、時間與光線變化，不把臨時 dressing 寫成永久地理。

### 空間語言

- **`craft_default`**：用“兩兩關係 + 視線終點”而非無序物件清單。例如“從捲簾門向內看，檢修臺沿右牆延伸，盡頭唯一安全門正對通道”。
- **`craft_default`**：優先保持一至三個強錨點，次要裝飾可概括，防止提示詞在細節噪聲中失去佈局。
- **`reviewed_invariant`**：同一 View 中的前後左右、入口和光向必須能共存；不能在一句中把同一門同時置於左右牆。
- **`taste_option`**：廣角或標準視角、對稱或偏心構圖、寫實或插畫由視覺方向決定。

## 4. 光線、氣氛與空場

### 光線連續性

說明主光來源與方向、時間/天氣關係、實際燈具及需要保留的暗區。不要只說“電影光”。若視覺風格要求冷色但場景有暖色實際燈，寫清主次關係而非刪掉其一。

### 跨 View 的光線一致性 (`IMG-10`)

上一條管的是**一個 View 內部**光向自洽。同一 Location 通常按觀察方向拆成多個 View
（例如同一條走廊分別做朝北與朝東兩塊板），這些板會被同一場戲的正反打互相剪接，
所以它們之間也要能對上。

**`reviewed_invariant`**：同一 Location 在同一時間/天氣 state 下的各個 View，必須共享
同一套主光來源、色溫關係與光比方向；差異只能來自已記錄的成因，並寫進對應的 delta。

同一地點、同一狀態的各觀察面要並排比較。色溫和主光不一致時，單板可能各自成立，
剪接後卻像不同時間或房間，逐板審查不足以發現這類問題。

對齊清單（同一 Location + 同一 time/weather state 內）：

- **主光來源**：是同一個窗、同一組燈具、同一片天空嗎？換 View 只應改變我們從哪一側看它，
  不改變它是什麼。
- **色溫關係**：冷暖主次是否一致。某塊板把暖色實際燈升為主光而別的板壓成次要，就是一次
  未記錄的變化。
- **光比與暗區方向**：亮暗落差的量級，以及暗區落在空間的哪一側。
- **實際燈具開關狀態**：同一 state 下不能一塊板亮著吊燈、另一塊板熄著。

允許且應當記錄的差異：View 朝向決定的逆光/順光關係、遮擋造成的區域性落影、以及朝窗與
背窗的自然亮度差。這些是同一光源在不同觀察方向下的正常表現，寫清來源即可，不需要拉平。

需要改光時（時段推進、停電、開燈、天氣轉變），走 delta：它是一個新的 time/weather state，
同一 Location 的**所有**已存在 View 都要一起交代如何變化，不能只改被用到的那一塊。

### `empty_stage` 政策

- `required`：不出現劇情角色、臨時群眾或敘事動作；固定傢俱/功能裝置保留。
- `preferred`：以空場為主，允許不具身份的尺度提示，但必須不妨礙地理讀取。
- `not_required`：可有人群或工作痕跡，但不能編造具體角色事件。

**`structural_invariant`**：`empty_stage: required` 與“主角站在入口”等演員要求顯式衝突。若確需人物尺度參照，先改政策或使用無身份中性參照，經創作者接受。

### 氣氛

把“壓抑、危險、溫暖”翻譯為已經有依據的空間選擇：通道狹窄感、光比、材質反射、空氣狀態、色溫關係。不得為氣氛新增劇情事故、封鎖出口或移動固定結構。

## 5. 輸出與審查

### 失敗徵兆

- 場景像裝飾清單，沒有入口、方向或相對位置；
- 為不同 View 搬動固定門窗，或把臨時箱子寫成永久錨點；
- `empty_stage` 要求空場卻出現演員、衝突人群或劇情動作；
- 夜雨狀態被混入晴天基準 plate，沒有 variant；
- 光線來源互相矛盾；所謂“寬闊”沒有任何尺度關係；
- 同一 Location 同一 state 的各 View 各自選了不同主光或冷暖主次，單看都成立、剪在一起
  卻像兩個時間。

### 檢查

| 檢查 | 分類 | 處理 |
|---|---|---|
| Location/View ID 與版本可解析 | `structural_invariant` | 未解析阻斷 |
| empty-stage 與人物要求顯式衝突 | `structural_invariant` | 先解決政策 |
| 地理、方向、固定錨點被保留 | `reviewed_invariant` | 審查者引用資產事實與提示詞 |
| 裝飾是否壓過佈局 | `craft_default` | 精簡無功能物件清單 |
| 光線是否可解釋且連續 | `reviewed_invariant` | 指出光源/方向衝突 |
| 同一 Location 同一 state 各 View 的主光、色溫與光比是否對齊 | `reviewed_invariant` | 並排比同組 View，差異需成因與 delta |
| 鏡頭審美與構圖 | `taste_option` | 保留創作者選擇 |

輸出一個 `IMG-...` 地點板條目和可複製正文；ID 留在標題，正文用清楚自然語言。不得生成地點板圖片。

## 6. 製作形態投影

`視覺設定.md` 的專案視覺方向與已明確製作形態決定這張場景板用什麼詞彙表達空間，不決定空間
長什麼樣。

### 從形態取什麼

- **背景密度與資訊層級**：繪製形態常靠密度差和留白建立主次，實拍形態常靠光比、景深和
  空氣層次；同一份地理在兩種形態裡選擇不同的詳略分配。
- **層拆**：固定地理層、可動層（簾、水、燈）、效果層各自畫什麼；哪些層在參考板上必須
  處於靜止的已接受狀態。
- **邊緣處理**：封閉輪廓、散邊、洇化或攝影式虛實——決定入口與錨點的邊界怎樣被讀出來。
- **材質對光的響應**：牆地頂的反射、粗糙與透明關係在該形態裡由什麼承擔（筆觸、平塗關係、
  真實光源）。
- **留白是否是合法的空間語言**：某些形態用留白表達縱深與壓力，這是可執行詞彙，不是省略。

### 形態不得改寫什麼

- 入口、路徑、固定錨點及其相對關係與觀察方向；
- `empty_stage` 政策與允許出現的人物類別；
- 標牌與介面的文字政策及承載面；
- 已接受的時間、天氣、光態版本與光源的可解釋來源。

**`reviewed_invariant`**：簡化掉的只能是裝飾，不能是本 View 必須可核對的地理證據。若形態
要求大面積留白或兩層平塗，先確定“從捲簾門向內看，檢修臺沿右牆延伸，盡頭唯一安全門正對
通道”這類關係仍然可讀；不能因為並進牆面更整齊就讓安全門消失。做不到時縮小留白範圍或
改選觀察面，並把衝突記為 `creator_decision_needed`，不靜默丟錨點。

同理，形態可以決定“氣氛靠什麼承擔”，但不得為了形態好看新增劇情事故、封鎖出口、移動固定
結構，或把臨時 dressing 提升為永久地理。
