# Lookdev 風格幀提示詞

Lookdev 風格幀把 `視覺設定.md` 中專案級視覺方向投影成可比較的通用圖片提示詞。它不選擇畫風，
不生成圖片，也不從一張參考圖推斷整部作品的規則。

## 三類測試軸

- `character_expression`：繫結準確 CHAR/LOOK，檢查身份錨點、材質/線條和表演可讀性；
- `core_location`：繫結準確 LOC/VIEW，檢查地理、材質、色彩層級與光源邏輯；
- `high_pressure_scene`：繫結準確場景、人物狀態與來源塊，檢查衝突中的注意中心、遮擋和密度。

不要求三類都固定生成若干張。選擇本專案最能暴露方向失效的代表幀，並在條目中寫清測試問題。

## 寫條目

在 `圖片提示詞.md` 使用 `IMG-...` 標題，寫明用途為 Lookdev、測試軸和對應的“專案視覺方向”章節。
高壓力場景還要繫結真實場景 ID、動作和資訊許可權，不能從提示詞發明劇情狀態。再寫：穩定項、
允許變化項、要保護的身份/地理/劇情事實，以及刪除風格標籤後真正改變的材質、光、色、邊緣、
景深或空間表達。

風格參考標明用途為“風格”：

- “允許控制”只列色彩層級、材質處理、陰影邊緣、景深傾向、畫面密度等本次准許內容；
- “不得控制”保護角色身份、固定場景地理、劇情狀態、人數、持物與道具文字；
- 每張真實參考圖使用穩定 `REF-...` 槽位，繫結可見專案相對路徑或其他明確的圖片定位資訊、中文名稱、顯式順序和封閉詞表裡的用途（風格幀通常是 `風格`）；換圖時明確修訂槽位的圖片定位資訊，不把舊圖的控制語義靜默轉給新槽位。`IMG-...` 僅用於當前《圖片提示詞.md》的提示詞條目。

角色、地點或壓力場景的事實仍來自各自負責的技能。高壓力測試幀不得為了“更有衝擊力”提前
洩露身份、發明動作結果或改變文字政策。

## 比較與修訂

比較人物、地點和壓力場景是否共享可辨認語言，同時記錄哪一部分允許逐場變化。沒有授權生成結果
觀察時，只能指出文字層風險。若收到繫結準確提示詞、參考、配置和結果的專案觀察，區域性修訂寫清
變化與保持項，一次只改診斷所需變數；不把一次結果推廣為其他專案或製作配置的規律。
