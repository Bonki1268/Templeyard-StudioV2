# 形態卡：實拍

上層選擇、構成差異與跨階段責任見 [production-form-profiles.md](../production-form-profiles.md)。
本卡回答：選了這個形態之後，可執行文字本身變成什麼樣。示例均為合成改寫。

## 敘事職責

讓觀眾用日常經驗直接讀出處境：衣服的舊、屋子的擠、手上的傷，不需要翻譯。實拍最擅長
承擔**當場證據與即時後果**——事實放在一個能搭建、能收音的空間裡，猶豫和選擇由表演
本身攜帶。跨越尺度、時間與非人身體的段落需要額外製作安排，應在 develop 階段比較可搭建版本、
效果方案或形態變化，按創作者選擇推進。

## 身份錨點載體

演員或真實參考已固定面部結構、身高和體態時，提示詞重點交接**造型狀態**：髮型走向與凌亂度、妝面完成度、服裝層次與穿法（袖挽到哪一截、扣到第幾顆）、
隨身物件的固定位置。沒有固定演員或參考時，仍須寫明可見身份錨點；造型說明使用可比較的狀態：
「左眉一道舊疤，右手食指常纏創可貼」可執行；「英俊堅毅」沒有任何可執行內容。

## 連續性載體

- **必須逐鏡傳遞**：造型層次與整潔度、溼/汙/傷的程度與位置、手中物與放置位置、
  光源時段與方向、妝發沿時間線的衰減。
- **可以省**：不出畫的服裝內層、觀眾無從比較的背景陳設、只在一鏡出現且不影響後果的道具細節。
- **最常斷裂處**：袖口與衣褶、菸酒食物的消耗量、傷妝的進展方向。

## 層級拆分

實拍的層不是畫面圖層，是**可控性分層**：

- 身份層：演員與造型，跨鏡鎖定；
- 環境層：可搭建空間、陳設、可用入口與遮擋體；
- 可動層：表演動作、道具操作、機位運動；
- 效果層：需要單獨安排的現場物理（煙、雨、火、閃光）。

每鏡重點寫發生變化的層；連續性鎖與執行所需的不變事實仍按原規則攜帶。

## 光與材質詞彙

可執行的光是**來源 + 方向 + 遮擋 + 反射 + 敘事用途**：窗在人物左後、百葉把光切成條、
桌面亞光不返光、金屬號牌是畫面裡唯一的高光點。材質寫能被光驗證的表面：起球的毛料、
洗得發白的棉、乾涸後發暗的血、溼透後貼身的布。色彩寫關係——誰最亮、誰最飽和、
什麼與什麼撞色。不可執行的寫法：電影感、高階灰、大師光、氛圍感。

## 運動預算

實拍預設全動作，人在畫面裡就在活著；預算問題是反過來的——**哪些必須被限制**。
需要控制的是同鏡並行動作數、道具交接的手數、台詞相對動作的先後位置。可由剪輯承接的：
長距離位移、換裝、時間跨度。必須在鏡內完成的：因果轉折點、證據交接、被看見的選擇。
不要把心理狀態預設翻譯成身體症狀（發抖、瞳孔放大、冷汗）當成表演方案。

## 聲音與文字職責

有敘事職責的現場聲源要寫清：誰在說、說話時手上在做什麼、哪條持續聲影響本場（空調、雨、走廊腳步）、
哪個聲音先於畫面進入。旁白只在專案已選擇旁白體時使用。可讀文字（合同、手機屏、門牌）
仍走資產的 text policy，不因為「實拍反正拍得到」就預設可讀。

## 跨階段傳遞

| 階段 | 這個形態額外要寫的 |
|---|---|
| develop | 確認這是可搭建、可表演、可收音的版本；標出需要特殊物理的段落為待試驗 |
| assets | 造型狀態版本、地點觀察視角與可用入口、道具的持有人與狀況 |
| image-prompts | 單幀的造型狀態與地理關係；不寫演員長相評價 |
| storyboard | 機位動機、可表演的起點姿態與持物、遮擋與資訊許可權 |
| video-prompts | 動作鏈順序、接觸與交接、台詞相對動作的位置、現場聲源 |
| review | 造型狀態與光源方向是否逐鏡可比較，特殊物理是否已被授權 |

## 常見失效

- 把情緒寫成症狀，用一套通用微表情替代人物正在處理的物件與選擇；
- 用形容詞代替光源，審查時無從比較；
- 讓一隻手同時完成三件事，或道具交接缺一次換手；
- 跨鏡衣著「自動整齊」、傷妝自動消退；
- 把需要特殊物理（水下、高空、動物、嬰兒）的段落當普通場景一路寫到底。
