# 場次視覺戲劇計劃

場次視覺計劃是正式分鏡前的可選思考層，回答整場怎樣改變觀眾位置、空間壓力、觀看節奏和聲音注意。
計劃繼承劇本事實，鏡頭邊界仍由正式分鏡決定。

## 什麼時候使用

只在導演選擇明顯影響體驗時使用：主要人物亮相、身份/證據揭示、關係反轉、高潮或結尾、複雜多人
排程、延遲資訊的懸念場、承擔視覺母題的場景。普通場景直接寫鏡頭，不增加表單。

## 在上下文比較什麼

使用場景標題 ID，例如 `EP001-SC003`，並結合當前視覺設定比較：

1. **戲劇轉向**：哪一種公開關係、資訊或選擇不可逆地改變；
2. **觀眾立場**：開場站在哪一方，結束被移到哪裡；
3. **空間壓力**：入口、距離、佔位、遮擋、讓路或退路怎樣承載人物策略；
4. **視覺推進**：什麼時候讓資訊、反應或空間先於特寫落地；
5. **攝影節奏**：固定、移動、切近和停留分別由什麼變化觸發；
6. **反應落點**：結尾畫面由誰的選擇或空間後果承擔；
7. **聲音策略**：主導聲源、主動留白、距離變化、撤出/恢復和聲音橋。

只有真正不同的方案才比較；不固定方案數、宮格、景別或鏡頭數。選定後直接把結果投影進
`分鏡.md` 的鏡頭職責、景別/機位、起止邊界與聲音，不另存 audition、plan 或接受記錄。

## 檢查

不按欄位完整度打分。檢查觀眾立場、知情時機、空間壓力或節奏是否發生有意變化；有意保持同一觀看
位置也可以成立，但必須說明它怎樣製造觀察、困住感或重新解釋同構畫面。再檢查空間、攝影和聲音是否
共同承擔同一轉向，而不是重複“中近景—反打—推鏡”。
