# 鏡頭修訂與穩定身份

鏡頭 ID 表示同一個編輯/導演決定的連續身份，不等於列表位置，也不等於外部製作任務編號。
修訂時先判斷鏡頭的敘事職責是否仍是同一個，再決定保留、建立或停用 ID。

## 身份規則

- **重排**：只改變順序，鏡頭目的與邊界職責不變時保留原 ID；重新整理依賴順序與相鄰邊界。
- **插入**：新增一個獨立注意或戲劇職責時建立新 ID；不要給後續所有鏡頭重新編號。
- **內容修訂**：同一鏡頭目的下調整構圖、走位或邊界，保留 ID 並更新當前文件。
- **拆分**：原鏡頭被兩個或更多獨立職責取代時，停用舊 ID，為每個新鏡頭建立新 ID；在修訂說明中
  寫清前身，不把舊 ID 偷給其中一個子鏡頭。
- **合併**：多箇舊鏡頭被一個新決定取代時，停用全部舊 ID，建立新 ID，並列出來源集合。
- **恢復**：停用的 ID 不復用於無關鏡頭；需要恢復同一職責時顯式說明關係。

普通新鏡只需要穩定 `SHOT-...`。拆分、合併或恢復舊職責時，在 `分鏡.md` 的修訂說明中列出前身、
後繼與停用 ID；沒有關係時不寫空模板。

## 每次拆分、合併或重排後的對賬

重新核對原文落實、場次視覺計劃、關鍵幀、`MOTION-...`、多鏡分組、相鄰起止邊界、總時長與審查
結論。舊 ID 只在修訂說明中解釋歷史，不能繼續被當前鏡頭或交付分組引用。

指令碼可以檢查引用、集合和算術；“是否仍是同一個導演決定”由智慧體根據鏡頭目的、資訊變化、
表演所有權和邊界職責判斷，不能用文字相似度或陣列位置硬判。
