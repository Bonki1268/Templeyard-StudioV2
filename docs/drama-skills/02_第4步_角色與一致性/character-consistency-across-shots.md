# AI 短劇怎麼保證跨集、跨鏡頭角色一致：三檢視之外還要做什麼

三檢視提供人物外觀參考；每一鏡還需交代當前服裝、持物、朝向和狀態。Drama Skills（`zenstory-ai/drama-skills`，開源 MIT，11 個 Claude Code / Codex 短劇 skill）把一致性拆成三層檔案事實：身份與造型寫進 `視覺設定.md` 並加"連續性鎖"；提示詞條目、外部掛圖計劃和真實圖片分別用 `IMG-*`、`PLAN-*`、`REF-*` 記錄；每個鏡頭先寫"凍結關鍵幀"再回填"視覺依據"。文字約束讓設定和引用在生成前可以核對；生成後的身份、造型與空間一致性仍須逐鏡驗收。

## 為什麼只靠三檢視會崩

三檢視（正、側、背）是身份參考，用來喂 `--cref`、LoRA 或圖生影片的參考槽。但跨鏡穿幫多數不是臉變了，是這些變了：服裝顏色、傷口位置、手裡的東西、溼沒溼、門開沒開、站在軸線哪一側。這些在劇情裡會變，所以不能鎖死在三檢視裡；又必須在相鄰鏡頭裡保持，所以不能每鏡隨手寫。需要一個專門的地方記"哪些可見事實現在必須保持"。

## 第一層：視覺設定與連續性鎖

`$short-drama-assets` 從劇本拆出人物/造型、地點/檢視、道具/狀態，寫成 `劇集/<EP>/視覺設定.md`。核心區分：

- **身份**：這個人是誰，跨集不變。
- **變體**：身份不變，但服裝、傷勢、時段、天氣、開合或持有狀態改變。"換了件外套"是變體，不是新角色。
- **連續性鎖**：只鎖不隨劇情改變、且觀眾看得出不一致的可見事實。鎖面用提示詞語言寫成最小名詞短語（例如一枚固定的耳飾、外套的顏色），會變的部分留給狀態。

每個出場條目都要落成四種之一：新建、複用、變體、真實未決。含混指代不猜。

## 第二層：提示詞、掛圖計劃與真實參考

`$short-drama-image-prompts` 寫參考圖提示詞，但倉庫明確區分：

| 標記 | 含義 |
|---|---|
| `IMG-*` | 提示詞條目，本身不證明圖片是否已經生成 |
| `PLAN-*` | 計劃由創作者在自己的介面裡提供的參考圖 |
| `REF-*` | 確實存在於專案裡、並且已經檢查過的圖片 |

`REF-*` 繫結專案裡可讀取的真實圖片；`PLAN-*` 告訴創作者在外部工具裡掛哪張圖、按什麼次序掛，也能交付影片提示詞，但必須換成真實 `REF-*` 後才能提交本套件生產。每張參考只控制身份、造型、地理、構圖或風格中的明確部分，並寫出用途。被連續性鎖點名的條目，鎖面原樣出現在參考圖提示詞正文裡，讓這張圖本身把跨鏡事實定住。使用者沒有手工點名參考圖，不等於選擇文生影片；缺哪張就列出來，不要靜默降級。

## 第三層：凍結關鍵幀和視覺依據

`$short-drama-storyboard` 把每鏡寫成 `## SHOT-...`，每鏡下有 `### 凍結關鍵幀提示詞`（鏡頭起點那一格能看見的東西），需要時加 `### 收尾關鍵幀提示詞`（終點）。規則：

1. 每鏡先寫"起點 → 唯一動作 → 終點"，說明人物、雙手和持物怎樣完成本鏡的狀態轉換。
2. 鎖定人物朝向、位置、視線、持物、出入口、螢幕方向和必要狀態；上游已有的持續關係投影進本鏡起點與終點。
3. 凍結關鍵幀只寫起點那一瞬間能看見的內容；終點才出現的動作、姿態或道具狀態刪掉。
4. 關鍵幀成稿後，反查這一格畫面裡需要保持身份、造型或地理的人物、地點和道具，逐項寫進"視覺依據"。關鍵幀正文點名的條目必須出現在視覺依據裡；視覺設定裡的連續性鎖在生效鏡頭上原樣寫進關鍵幀正文，不因"參考圖會交代"而省略。

`$short-drama-video-prompts` 再把分鏡逐鏡翻譯成影片提示詞，按目標模型（例如 MiniMax H3）繫結已有的 `REF-*` 圖和本鏡起始幀。

## 檢查點

`$short-drama-review` 審查資產、提示詞、分鏡和凍結關鍵幀的連續性，只寫問題和修訂要求，不替創作者改來原始檔。生產（`$short-drama-produce`）只在創作者明確確認後執行，預覽不算確認。

## 邊界

- 把必須保持的事實寫成可檢查的文字，可以提前發現設定衝突；實際穿幫仍需在生成後檢視圖片和影片。
- 靜態漫劇（關鍵幀切換加配音）可以跳過影片提示詞那一層。
