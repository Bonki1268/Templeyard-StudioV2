你負責完成廟埕影室的**一個**開發階段，輸入是階段編號 N（可能附上額外指示）。

## 開始前

1. 讀 `CLAUDE.md`、`docs/PROGRESS.md`。
2. 讀 `docs/06-Implementation-Plan.md` 中第 N 階段的段落與完成條件。
3. 依 `CLAUDE.md` 的文件地圖，讀這個階段需要的其他文件；至少讀 `docs/01-PRD.md` 中對應的 F 與「這一版不做的東西」。
4. 如果 PROGRESS 的階段狀態不是「未開始」，表示上次做到一半：從記錄的狀態接著做，不要重來。紅燈 commit 已存在就不要再寫一次測試。

## 做法

照 `CLAUDE.md`「每個階段怎麼做」的 5 個步驟做完；每進入下一步就更新 PROGRESS 的「階段狀態」。第 0 階段另外照「第 0 階段的特別做法」。

只做第 N 階段的範圍；發現後面階段才需要的東西，寫進階段報告的「等你處理」或備註，不要先做。

## 停下來

遇到 `CLAUDE.md`「停下來的條件」時：

- PROGRESS 的「階段狀態」改為「停止」，把原因與需要使用者決定的事寫進「等你處理」，同時寫進 `docs/progress/stage-NN.md`。
- 不要 commit 測試沒通過的實作；未完成的變更留在工作區，在報告中說明。紅燈的測試 commit 不受此限。
- 然後結束，不要繞過問題。

## 回報

結束時回報（繁體中文，30 行以內）：

- 結果：完成／停止
- 測試提交的 hash、最後一個 commit 的 hash
- 對應的 F、情境數、單元測試數（紅燈時失敗數、綠燈時通過數）
- 等你處理
